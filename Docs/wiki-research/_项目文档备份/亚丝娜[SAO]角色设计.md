# 亚丝娜[SAO]角色设计

> 本文集中记录亚丝娜【SAO】的技能资料、追击结算、实际玩法、设计评价和可复用经验。角色设计以SAO中期的“闪光”与血盟骑士团副团长为主要切入点。圣母圣咏来自既有素材限制，不作为该时期角色性格与设计意图的依据。

## 一、角色设计概览

### 1. 基础定位

- 速度值：758
- 物理抗性
- 物理副C
- 前排攻击
- 追击
- 低耗费
- 闪避守备

这些标签首先说明亚丝娜在游戏中的战术用途。她真正的专属玩法不只是“速度快”，而是抢先建立攻略之鬼，再利用三名我方角色各自结束回合的时机连续追击。

### 2. 角色时期

这个版本集中表现SAO中期的亚丝娜：她已经是血盟骑士团副团长，也是以攻略效率和战术判断为优先的攻略组核心。

设计灵感来自她与桐人对NPC村民价值产生争执的情节。亚丝娜当时认为村民并非真正生命，并让士兵保持待命，以村民承受怪物攻击来制造怪物出招后的军队进攻间隔。

技能组没有直接复刻“牺牲村民”，而是提取了其中的行为逻辑：

> 先完成战术部署 → 让其他成员依次行动 → 利用每次行动结束后的间隔追击

因此，玩家管理的不是亚丝娜自己的专属层数，而是全队的行动顺序和本轮尚未结束回合的角色数量。

## 二、被动：超速支援

每当一名我方角色结束自己的回合时，亚丝娜都会对当前拥有后排Tag的敌人进行一次追击，造成相当于目标最大生命值2%的伤害。

若目标在追击开始前，当前生命值已经低于最大生命值的2%，则不再结算本次普通追击，而是立即处决目标。

### 1. 触发次数

“我方行动结束”按角色回合计算。队伍共有三名角色，因此一轮中共有三次正常触发机会，其中也包括亚丝娜自己结束回合。

连携、护援、守备、反击或其他追击若发生在某名角色的回合过程中，不会各自被视为新的角色回合结束，也不会额外增加超速支援的触发次数。

这使超速支援拥有明确上限，避免追击继续触发追击或通过额外动作无限套娃。

### 2. 目标位置

超速支援始终读取敌方当前的后排Tag。原后排死亡后，系统会按照全局站位规则为剩余角色重新分配前、中、后排Tag，亚丝娜随后攻击新的后排目标。

这不是亚丝娜独有的动态换目标机制，而是所有站位技能共同遵循的底层逻辑。亚丝娜的专属规则只是每次追击都指定当前后排。

### 3. 追击与处决顺序

结算顺序是：

1. 找到当前拥有后排Tag的目标。
2. 检查目标是否已经低于最大生命值的2%。
3. 若低于2%，立即处决。
4. 若未低于2%，结算本次2%或5%最大生命值追击。

因此，本次追击若刚刚把目标压到2%以下，不会在同一次触发中追加处决。需要等下一名我方角色结束回合，再于下一次追击开始前完成处决。

## 三、技能资料

### 1. 一技能：四重痛楚

| 项目 | 内容 |
| --- | --- |
| 费用 | 0技能点 |
| 目标 | 前排攻击 |
| 守备 | 闪避（2） |
| 物理倍率 | 40% / 100% / 180% / 300% / 340% |
| 异能倍率 | 无 |
| 特殊效果 | 无 |

四重痛楚提供0费前排攻击和基础闪避，是亚丝娜低耗费定位的主要组成部分。

### 2. 二技能：中子冲击

| 项目 | 内容 |
| --- | --- |
| 费用 | 2技能点 |
| 目标与标签 | 自身加攻 |
| 守备 | 闪避（3） |
| 物理倍率 | 50% / 120% / 210% / 240% / 340% |
| 异能倍率 | 无 |
| 特殊效果 | 技能成功释放时，获得1层攻略之鬼 |

中子冲击是主玩法的启动技能。攻略之鬼存在时，超速支援的追击伤害会由目标最大生命值的2%直接提高到5%。

### 3. 护援技：幻闪流星

| 项目 | 内容 |
| --- | --- |
| 费用 | 4技能点 |
| 目标 | 后排封技 |
| 守备 | 闪避（3） |
| 物理倍率 | 20% / 50% / 100% / 180% / 240% |
| 异能倍率 | 无 |
| 特殊效果 | 技能结束时，对攻击目标施加1层待命指示 |

幻闪流星只在亚丝娜位于Sub位置时使用，不运行主战状态下的追击部署。它以一次独立的后排封技表现副团长的战场命令。

### 4. 终结技：圣母圣咏

| 项目 | 内容 |
| --- | --- |
| 费用 | 10升华点 |
| 目标 | 前排终结 |
| 守备 | 闪避（5） |
| 物理倍率 | 200% / 380% / 780% / 1200% / 1400% |
| 异能倍率 | 无 |
| 特殊效果 | 技能成功释放时，自身获得10层闪光 |

10层闪光会暂时提高400速度，使亚丝娜更容易在后续回合先于另外两名队友行动，并提前使用中子冲击建立攻略之鬼。

圣母圣咏并非SAO中期亚丝娜当时已经掌握的招式。它出现在本技能组中是因为复活旧版《零境交错》时可用素材有限，属于素材妥协，而非刻意合并角色时间线。

## 四、特殊效果

| 效果 | 最大值 | 持续时间 | 作用 |
| --- | ---: | ---: | --- |
| 攻略之鬼 | 1 | 2 | 使超速支援的追击伤害由目标最大生命值2%直接提高为5% |
| 闪光 | 10 | 2 | 每层暂时提高40速度，10层共提高400速度 |
| 待命指示 | 1 | 2 | 存在期间封印持有者的全部技能 |

### 1. 攻略之鬼

攻略之鬼不是“在原追击伤害基础上增加5%”，而是把追击伤害直接改为目标最大生命值的5%。

一轮有三次角色回合结束，因此在三次追击均受到攻略之鬼强化的理想情况下，亚丝娜一轮可以对当前后排及其继任目标累计造成相当于15%最大生命值的追击伤害。

### 2. 闪光

闪光没有直接提高追击次数或追击倍率，而是改变下一阶段的行动顺序。亚丝娜越早行动，越能让本轮剩余角色的回合结束触发强化追击。

### 3. 待命指示

待命指示可以作用于Boss，并且再次施加时可以刷新持续时间。当前可以通过反复使用幻闪流星延长封技；未来可能出现免疫封技的Boss，但具体免疫规则尚未确定。

## 五、实际玩法

### 1. 基础追击

没有攻略之鬼时，三名角色各自结束回合会带来三次2%最大生命值追击，理论上一轮累计6%。亚丝娜会始终攻击当前后排Tag的敌人，并在原后排死亡后按照公共站位规则继续攻击新的后排。

### 2. 攻略窗口

理想顺序是让亚丝娜先使用中子冲击：

1. 亚丝娜成功获得攻略之鬼。
2. 亚丝娜自己的回合结束，触发第一次5%追击。
3. 第二名角色结束回合，触发第二次5%追击。
4. 第三名角色结束回合，触发第三次5%追击。

这样可以在一轮中完整利用三次强化追击。若其他队友先于亚丝娜行动，他们此前的回合结束只能触发未强化的2%追击。

### 3. 闪光与下一轮部署

圣母圣咏本身是高倍率前排终结技，成功后获得的400速度则服务于后续回合。它帮助亚丝娜重新抢到首位，再用中子冲击建立下一段攻略窗口。

因此，大招的速度收益不是单纯展示“闪光很快”，而是在前排爆发以后维持副团长先部署、队员后行动的队伍节奏。

### 4. 从后向前的战场压力

亚丝娜的一、二技能和终结技主要作用于前排，超速支援则指定当前后排。她本人正常行动压制阵容正面，被动追击持续处理阵容末端。

后排目标死亡后的Tag继承属于公共站位系统，但前排主动攻击与后排被动追击的组合仍然构成了亚丝娜自己的战场覆盖方式。

## 六、护援技与Sub边界

### 1. 幻闪流星不运行主战循环

亚丝娜处于Sub位置时，玩家围绕当前主战角色行动。幻闪流星不会要求玩家先获得攻略之鬼，也不会额外展开闪光与超速支援的完整玩法。

这遵守了护援技的基本边界：Sub提供一次独立、清楚的帮助，不在同一回合抢占主战角色的决策中心。

### 2. 独立技能仍然保留角色认识

幻闪流星通过待命指示封印当前后排全部技能。它不共享主战资源，却能单独表现副团长发布命令、限制敌方行动和控制战场节奏。

与单纯造成伤害的护援技相比，它是一个较完整的例子：不复刻本体循环，但仍然让人认出这个时期的亚丝娜。

## 七、闪避专精与Sub配队

### 1. 全闪避不是技能组缺陷

亚丝娜的一技能、二技能、护援技和终结技全部使用闪避守备。这使她成为明确的闪避专精角色，而不是在自身技能组内覆盖防御、反击和闪避三种答案。

### 2. 其他守备由Sub补足

玩家可以通过Sub角色改变整个角色组合可使用的守备类型：

- 搭配闪避Sub，继续强化高速回避特色。
- 搭配防御Sub，用守备值处理多段攻击或闪避次数不足的情况。
- 搭配反击Sub，获得拼刀和主动还击能力。

因此，守备选择并未消失，而是从亚丝娜单人技能选择前移到了队伍编成。玩家需要根据关卡决定保留专精，还是通过Sub换取更完整的防守覆盖。

### 3. 与桐人的差异

桐人自身集齐三类守备，选择发生在角色行动过程中；亚丝娜自身贯彻闪避，选择则发生在Sub搭配阶段。

这说明角色不必独自拥有完整答案。只要不同Sub确实各有适用场景，角色有意留下的守备缺口也可以成为配队自由的一部分。

## 八、设计优点

### 1. 抓住了具体时期而非泛用印象

技能组没有把亚丝娜概括成高速剑士、治疗者和桐人搭档的合集，而是集中表现SAO中期的闪光、副团长和攻略之鬼。

### 2. 将剧情思维转化为玩家行为

设计没有直接复刻NPC牺牲，而是提取“利用其他单位行动制造攻击间隔”的战术逻辑。玩家会主动安排亚丝娜先部署，再让队伍成员依次为她创造追击时机。

### 3. 以全队回合代替专属资源条

亚丝娜真正管理的是本轮还有几名角色尚未结束回合，而不是另一套叠层资源。三个固定回合结束点构成了可预测的追击预算，也避免三个连续角色都采用“积累专属层数”的重复结构。

### 4. 速度具有实际战术作用

758基础速度和闪光的400速度都服务于抢先建立攻略之鬼。速度不只是面板对原作称号的还原，而会改变本轮能够获得几次强化追击。

### 5. 追击与处决互相补全

最大生命百分比追击容易留下少量残血，2%处决线负责在下一次追击开始时完成收尾。两者形成削减、压入斩杀线、下一次触发处决的连续节奏。

### 6. 熟悉特征与冷门侧面互相支撑

高速、细剑与闪避让玩家认出“闪光”；攻略之鬼、回合追击和待命指示则把她从普通高速剑士中区分出来。

### 7. 护援技遵守位置边界

幻闪流星不携带本体循环，却以一个清楚的封技效果保留指挥者风味。它没有与主战角色争夺玩法，又不是完全无辨识度的通用攻击。

### 8. 闪避专精为Sub选择留下空间

亚丝娜自身不覆盖全部守备，玩家可以通过Sub决定继续强化闪避，还是补入防御或反击。角色专精与队伍自由在不同层级同时存在。

## 九、缺点与风险

### 1. 最大生命百分比追击需要严格控制

攻略之鬼期间，一轮三次5%追击理论上可以累计15%最大生命值伤害。这种伤害不依赖普通技能倍率，高血量Boss反而会提供更高的绝对收益。

如果缺少Boss修正、伤害上限或其他约束，亚丝娜可能用固定轮数削减所有高血量敌人，压缩养成属性与普通输出角色的意义。

### 2. 最优行动顺序可能逐渐固定

理想流程高度清楚：亚丝娜先使用中子冲击，另外两名队友随后行动。速度轴调整完成后，玩家的临场判断可能减少，玩法从战术部署退化成每轮重复固定顺序。

### 3. 自动指定当前后排限制目标选择

公共站位Tag保证追击始终有合法目标，但玩家不能自由选择更需要处理的敌人。若当前后排威胁较低而中排才是关键目标，超速支援仍会服从后排目标规则。

这符合纪律明确的自动支援，但不适合照搬给强调自由判断和精确选敌的角色。

### 4. 可刷新Boss封技容易形成二元对局

在Boss不免疫时，反复施加待命指示可能长期限制其全部技能；一旦关卡直接免疫封技，幻闪流星的核心价值又会完全消失。

这种设计容易让关卡落入“能够持续控制”与“完全不吃控制”两个极端，需要谨慎处理Boss抗性和刷新规则。

### 5. 冷酷剧情不能概括全部人格

攻略优先的剧情非常适合解释攻略之鬼，但若所有技能、台词和演出都强调牺牲、命令与处决，就可能把冷静负责的副团长简化成单纯残酷的人。

值得保留的是她计算攻击间隔、承担攻略责任的思维，而不是无限放大对NPC生命的漠视。

### 6. 闪避专精依赖Sub生态平衡

全闪避本身不是问题。真正的风险是某一种防御或反击Sub如果明显优于其他搭配，就可能变成亚丝娜的唯一答案，使原本的配队选择重新被锁死。

因此，需要平衡的是Sub之间的适用场景，而不是强行把其他守备类型塞回亚丝娜本体。

## 十、设计意图分析

根据技能结构和设计者补充，可以基本确认：

- 角色重点不是单纯表现速度，而是表现攻略组副团长利用全队行动间隔组织进攻。
- 中子冲击负责在亚丝娜先手时建立攻略窗口，攻略之鬼把三次追击由2%提高为5%。
- 超速支援固定追击当前后排，用于在亚丝娜主动攻击前排的同时持续处理阵容末端。
- 处决在追击前判断，用于收掉上一段追击留下的极低血量目标。
- 闪光提高后续速度，是为了帮助亚丝娜继续先于队友部署，而不只是展示称号。
- 待命指示来自副团长发布命令、让单位保持待命的角色认识。
- 护援技不接入主战循环，是为了避免Sub角色抢占当前主战玩法。
- 全技能闪避用于建立清楚的角色专精，防御与反击通过Sub搭配补足。

需要区分的边界包括：

- 后排死亡后其他角色获得后排Tag，是公共站位逻辑，不是亚丝娜专属能力。
- 物理副C、前排攻击、追击和闪避守备首先是游戏定位，不能单独证明角色性格。
- 圣母圣咏来自素材有限造成的时间线妥协，不能作为SAO中期设计意图的原作证据。

## 十一、值得学习的设计方法

### 1. 从具体时期提取角色行为

先确定角色处于什么阶段，再寻找当时最有辨识度的判断方式。具体时间切片通常比把角色全部经历塞进一套技能更容易形成统一玩法。

### 2. 提取剧情逻辑，不必照搬剧情表面

角色设计可以把剧情中的决策方式变成战斗规则，而不需要复现原事件中的人物、场景和结果。

### 3. 使用公共时间结构作为角色资源

角色不一定需要专属层数。队友回合、行动顺序、剩余触发次数和目标站位都可以成为玩家实际管理的资源。

### 4. 让速度服务部署顺序

速度类角色不应只获得更多速度数值。速度需要影响她能否先建立状态、抢占窗口或改变队伍计划，才能成为真正的玩法。

### 5. 为自动机制设置清楚边界

超速支援明确按三个角色回合结束触发，而不是按所有动作触发。自动追击只有在触发来源、次数上限、目标和结算顺序全部清楚时才适合进入正式设计。

### 6. 让补充机制解决核心机制的自然问题

处决不是独立炫技，而是解决百分比追击容易留下残血的问题。附加效果最好补全主机制的缺口，而不是与主玩法争夺注意力。

### 7. 主战与Sub可以共享人物认识而不共享资源

主战亚丝娜通过队伍行动表现指挥，Sub亚丝娜通过待命指示表现命令。两者玩法不同，但仍然指向同一时期的角色。

### 8. 将角色专精与组合自由放在不同层级

亚丝娜本体贯彻闪避，Sub负责补充防御或反击。不要为了让单个角色功能完整而抹平其专精，可以把一部分选择留给队伍编成。

## 十二、不宜直接照搬的部分

### 1. 不要把最大生命百分比追击作为通用追击结构

值得学习的是利用队友回合制造攻击窗口，而不是每名队友行动后都固定削减敌人最大生命值。具体伤害形式需要根据角色和关卡生态重新设计。

### 2. 不要让先手BUFF成为永远固定的唯一开局

若角色每轮都必须先使用同一个技能，后续队友顺序也完全固定，行动顺序就只剩预设答案。其他角色需要根据其战斗风格保留不同的临场变化。

### 3. 不要依赖永久封锁与完全免疫互相对冲

反复刷新强控制，再用Boss免疫解决，会让技能在不同关卡间从决定胜负变成完全无效。强控制需要慎重控制持续时间、刷新和抗性关系。

### 4. 不要把一段极端剧情扩展成完整人格

剧情切片用于提炼行为，但仍需保留角色其他能够支撑该时期的特征。亚丝娜既是攻略之鬼，也是以高速细剑作战、承担团队责任的闪光。

### 5. 不要把公共站位补位误写成角色能力

后排死亡后目标变化是全局Tag继承规则。评价角色时必须先剥离底层系统行为，再判断剩余机制是否真的属于角色。

### 6. 不要把所有高速角色都做成全闪避

亚丝娜的全闪避来自明确专精，并且有Sub系统提供其他守备。其他高速角色若没有相同配队环境和原作依据，不应直接复制这套配置。

### 7. 不要把素材妥协反过来解释成原作意图

旧素材可以在现实条件下继续使用，但文档和分析必须标出时间线误差，避免从不符合时期的招式倒推角色性格。

## 十三、待补充边界

- 最大生命百分比追击是否受到普通增伤、减伤和防御结算影响。
- 攻略之鬼与闪光的持续时间在具体回合节点如何减少。
- 未来Boss封技免疫的范围、提示和判定方式。

这些内容在确认前不写成既定规则。

## 十四、总结

亚丝娜最值得保留的设计核心是：

> 先由副团长建立攻略窗口，再让三名角色依次结束回合，为闪光创造三次从后排开始的高速追击。

她没有管理新的专属资源条，而是把全队回合顺序变成自己的战术资源。速度保证她先部署，攻略之鬼强化追击，处决收掉上一段追击留下的残血，待命指示则在Sub位置独立表现命令与控制。

需要谨慎的部分是最大生命百分比追击、固定速度轴和可刷新Boss封技。后排目标随阵容变化属于公共站位Tag逻辑，不应计入亚丝娜的专属创新；全闪避则是有意保留的角色专精，其余守备由玩家通过Sub搭配决定。
