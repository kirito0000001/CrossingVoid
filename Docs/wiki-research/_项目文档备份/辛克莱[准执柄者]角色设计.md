# 辛克莱[准执柄者]角色设计

> 本文集中记录辛克莱【准执柄者】的技能资料、SAN与狂信结算、侵蚀规则、实际玩法、原版对照、设计评价与可复用经验。数值区间和结算顺序以设计者在讨论中确认的规则为准。

## 一、角色设计概览

### 1. 基础定位

- 速度值：999
- 物理抗性
- 物理主C
- 前中排攻击
- 无须启动
- 防御守备

### 2. 核心体验

辛克莱以SAN表示逐渐加深的精神失控。由于当前BUFF系统不能使用负数，原版向负值下降的理智被反向表现为从0向45上升的SAN：

- SAN越高，辛克莱造成的伤害越高。
- SAN越高，终结技消耗的升华点越少。
- SAN达到45时，辛克莱进入侵蚀并锁定自己人。
- 使用守备和结束自身行动可以降低SAN。

玩家需要把辛克莱维持在接近失控的位置，完整利用已经获得的力量，再决定是否为了更低的终结技费用和更高伤害越过45。

这套角色不是普通的攒满资源后爆发。45不是奖励终点，而是一条必须支付友伤代价的失控线。

## 二、SAN

### 1. 基础规则

- 最大值：45
- 初始值：40
- 持续时间：无限
- 辛克莱结束自己的行动后，减少10 SAN。
- SAN变化会动态更新对应的最终伤害修正。
- 达到45 SAN时立即进入侵蚀锁定。

初始40意味着辛克莱第一回合就处于最高伤害区间，并可以直接使用0费终结技。行动开始时不会预先减少SAN，因此已经积累的SAN可以被完整利用一次。

### 2. 最终伤害修正

| 当前SAN | 最终伤害修正 |
| ---: | ---: |
| 0至9 | -30% |
| 10至19 | -10% |
| 20至29 | 无修正 |
| 30至34 | +10% |
| 35至39 | +20% |
| 40至45 | +50% |

高SAN同时提高伤害和降低终结技费用。玩家因此会自然产生继续推高SAN的欲望，但45会把这种收益转化为一次必须兑现的侵蚀代价。

### 3. 行动结束回落

SAN在辛克莱结束自己的行动后减少10，而不是在行动开始时减少。这个时点有两项重要作用：

- 队友在辛克莱行动前积累的SAN不会被提前浪费。
- 40至44的高SAN区间能够完整服务辛克莱的一次主动行动。

如果在行动开始时先减少10，那么44会在辛克莱真正出手前变成34，最高档位就很难成为可利用的状态。当前规则避免了这个问题。

## 三、狂信（现用名称）

### 1. 基础规则

- 最大层数：30
- 持续时间：无限
- 狂信施加在敌方目标身上。
- 它代表辛克莱认定的净化目标。

带有狂信的角色被辛克莱以外的角色攻击时：

1. 每一段命中消耗1层狂信。
2. 每消耗1层狂信，使辛克莱获得2 SAN。

狂信是有限层数资源。攻击段数不会增加狂信的总收益，只会改变已有层数被兑现的速度。

### 2. 高频与低频角色

高频角色可以在一次技能中快速消耗多层狂信，使辛克莱迅速获得SAN。低频角色消耗较慢，可以让狂信保留更久。

因此两类角色的区别是兑现速度，而不是收益上限：

- 辛克莱SAN较低时，可以让高频角色快速消耗狂信。
- 辛克莱接近45时，可以改用低频角色或停止攻击该目标。
- 狂信耗尽后，剩余攻击段数不会继续产生SAN。

未来角色拥有更多攻击段数，也不会凭空扩大辛克莱的SAN总收益。真正决定总收益的是狂信的施加层数。

### 3. 当前命名问题

原版“狂信”是施加在辛克莱自身的状态，表示他陷入狂热；当前设计却把它施加在被净化的敌人身上。玩法本身成立，但名称已经不再准确。

后续文本整理时，建议将敌方状态改为下列名称之一：

- 异端
- 净化目标
- 异端烙印

其中“异端”最简洁，也能直接组成“攻击带有异端的目标时”的规则文本。这里应当保留已经成立的玩法，放弃语义发生改变的原作名词。

## 四、被动技能

### 1. 人格覆盖

人格覆盖根据辛克莱当前SAN，动态改变终结技费用和额外施加的狂信层数。

| 当前SAN | 终结技费用 | 人格覆盖施加狂信 |
| ---: | ---: | ---: |
| 0至9 | 10升华点 | 10层 |
| 10至19 | 8升华点 | 6层 |
| 20至29 | 6升华点 | 4层 |
| 30至34 | 4升华点 | 2层 |
| 35至39 | 2升华点 | 1层 |
| 40至45 | 0升华点 | 0层 |

人格覆盖与“净化异端”分别结算。终结技成功造成伤害时，还会通过净化异端额外施加1层狂信。

因此在不考虑30层上限时，终结技实际可以留下：

| 当前SAN | 实际狂信总量 |
| ---: | ---: |
| 0至9 | 11层 |
| 10至19 | 7层 |
| 20至29 | 5层 |
| 30至34 | 3层 |
| 35至39 | 2层 |
| 40至45 | 1层 |

低SAN终结技费用昂贵，但会留下更多狂信，为后续重新提高SAN准备资源；高SAN终结技费用低，却只能留下很少狂信。这让终结技同时承担爆发与下一轮资源准备。

### 2. 够了……

带有狂信的目标攻击辛克莱时，每一段命中使辛克莱获得1 SAN。

这项被动不能令辛克莱达到45 SAN，最多只能将他推到44。它允许玩家利用敌方高频攻击快速接近最高输出区间，同时保留一层不会被敌人直接触发的安全边界。

由于效果按每段命中计算，敌方攻击范围和辛克莱站位会影响SAN增长：

- 敌方高频攻击前排时，将辛克莱放在前排可以更快获得SAN。
- 接近侵蚀线时，可以通过调整站位减少被高频攻击覆盖。
- 该被动不会独自造成侵蚀，真正越过45仍需其他SAN来源。

### 3. 侵蚀

自身SAN达到45时，辛克莱锁定自己人作为攻击目标。

- 侵蚀攻击沿用所选技能原本的站位目标规则。
- 选择友方目标时首先排除辛克莱自己。
- 必须完成一次对自己人的攻击，SAN才会解除锁定并重新允许变化。

侵蚀不是简单扣血或降低属性，而是一笔必须以实际行动偿还的债务。玩家不能在达到45以后立即通过普通SAN回落逃避代价，只能提前控制SAN，或者安排合适的队友承受侵蚀攻击。

### 4. 调整目标

辛克莱使用守备技能时，自身减少5 SAN。

守备是主动泄压手段。玩家以放弃本次技能原有效果为代价，把辛克莱从侵蚀边缘拉回较安全的区间。

守备结束后仍会经历本人行动结束时的10 SAN回落，因此在未进入锁定的情况下，一次守备行动可以明显降低SAN。

### 5. 净化异端

辛克莱对目标成功造成伤害时，给目标施加1层狂信。

这项被动让一、二技能和终结技都能建立狂信目标。辛克莱负责指定需要净化的对象，其他角色随后通过攻击段数把狂信转化为辛克莱的SAN。

## 五、技能资料

### 1. 一技能：迫不得已的审判

| 项目 | 内容 |
| --- | --- |
| 费用 | 2技能点 |
| 目标 | 前中排攻击 |
| 攻击标签 | 锤钉 |
| 守备 | 防御90% |
| 物理倍率 | 50% / 130% / 220% / 270% / 340% |
| 特殊效果 | 无独立效果；成功造成伤害后通过净化异端施加1层狂信 |

一技能承担较低费用的常规攻击和狂信起点。它不会直接增加自身SAN，而是先为队友建立可以消耗的目标状态。

### 2. 二技能：黑白不分的执行

| 项目 | 内容 |
| --- | --- |
| 费用 | 6技能点 |
| 目标 | 前排攻击 |
| 攻击标签 | 挥打 |
| 守备 | 防御80% |
| 物理倍率 | 200% / 300% / 450% / 700% / 900% |
| 特殊效果 | 无独立效果；成功造成伤害后通过净化异端施加1层狂信 |

二技能是高费用、高倍率的正面打击。它与一技能在SAN循环中的作用相近，主要差异来自技能点消耗、攻击范围和伤害规模。

### 3. 护援技：砸！

| 项目 | 内容 |
| --- | --- |
| 费用 | 0技能点 |
| 目标 | 前排攻击 |
| 攻击标签 | 终结 |
| 守备 | 防御90% |
| 物理倍率 | 160% / 280% / 420% / 640% / 700% |
| 特殊效果 | 无 |

护援技只在辛克莱位于Sub位置时使用，不需要强行接入Main位置的SAN完整循环。它是独立的0费前排攻击。

### 4. 终结技：自我毁灭的净化

| 项目 | 内容 |
| --- | --- |
| 费用 | 根据当前SAN在0至10升华点之间动态变化 |
| 目标 | 前排攻击 |
| 攻击标签 | 毁灭 |
| 守备 | 防御90% |
| 物理倍率 | 40% / 100% / 300% / 400% / 450% |
| 特殊效果 | 成功释放时，自身获得15 SAN；人格覆盖根据释放前SAN决定费用和狂信层数 |

终结技是SAN循环的集中兑现点：

- 释放前SAN决定本次升华点费用。
- 成功释放后增加15 SAN。
- SAN变化会动态更新伤害修正，不会锁定在按钮按下前的档位。
- 人格覆盖和净化异端共同决定目标获得的狂信层数。
- 如果SAN达到45，则进入侵蚀锁定。

高SAN时，终结技便宜、伤害高，但容易立即侵蚀；低SAN时，终结技昂贵，却能在释放过程中提高自身伤害档位，并留下更多狂信供队友重新推动循环。

## 六、关键结算顺序

### 1. 普通攻击

1. 辛克莱使用一技能或二技能攻击目标。
2. 成功造成伤害后，通过净化异端施加1层狂信。
3. 其他角色后续攻击该目标时，每段消耗1层狂信。
4. 每消耗1层，使辛克莱获得2 SAN。
5. 辛克莱在自己的下一次行动中完整利用当前SAN。
6. 辛克莱行动结束后减少10 SAN。

### 2. 终结技

1. 读取释放前的当前SAN。
2. 人格覆盖据此确定终结技费用和额外狂信层数。
3. 终结技成功释放，使辛克莱获得15 SAN。
4. SAN对应的动态最终伤害修正随数值变化立即更新。
5. 对目标造成伤害。
6. 人格覆盖施加对应狂信，净化异端再额外施加1层。
7. 若SAN达到45，进入侵蚀锁定。
8. 未被侵蚀锁定时，行动结束后减少10 SAN。

### 3. 侵蚀

1. 辛克莱达到45 SAN，锁定友方目标。
2. 目标范围沿用所选技能规则，并排除辛克莱本人。
3. 辛克莱完成一次对自己人的攻击。
4. 侵蚀债务完成后，SAN重新允许变化。

## 七、实际玩法

### 1. 第一回合

辛克莱初始拥有40 SAN，因此第一回合可以直接使用0费终结技并获得50%最终伤害提升。

玩家面临两条路线：

- 立即使用终结技，获得最高档位爆发，但15 SAN会把辛克莱推到45并触发侵蚀。
- 先使用普通技能建立狂信目标，行动结束后SAN回落到30，为后续团队循环准备更安全的空间。

0费终结技并非没有代价。它将强度提前交给玩家，同时把一次友伤作为后续债务。

### 2. 团队推动

辛克莱攻击并标记目标以后，其他角色决定狂信的兑现速度：

- 高频技能快速消耗多层狂信，迅速提高SAN。
- 低频技能缓慢消耗狂信，保留更多后续调整空间。
- 接近45时，玩家可以停止攻击该目标、改变攻击目标或使用低频技能。

玩家需要同时观察狂信层数和当前SAN，而不是简单把所有多段攻击一次性打出。

### 3. 利用敌方攻击

带有狂信的敌人攻击辛克莱时，每段攻击都能通过“够了……”提高SAN，但不会令他达到45。

玩家可以根据敌人的目标标签安排辛克莱站位，让高频敌人帮助他到达44；也可以在SAN较高时避开这些攻击。敌人的攻击方式因此成为辛克莱资源循环的一部分。

### 4. 守备泄压

当当前SAN、敌方攻击段数和队友后续行动可能把辛克莱推入45时，玩家可以使用守备减少5 SAN。

守备会放弃原技能效果，因此它不是无成本修正数字，而是以一次进攻机会换取对侵蚀风险的控制。

### 5. 侵蚀止损

一旦达到45，玩家已经无法撤回这次失控。此时能够控制的是损失落在哪里：

- 选择目标范围较窄的技能。
- 调整前中后排站位。
- 让守备能力较强或当前状态更适合承伤的队友进入对应位置。

侵蚀因此既有不可逃避的代价，也保留了阵容与站位层面的止损空间。

## 八、与《边狱巴士》原版准执柄者的对照

### 1. 原版核心

原版准执柄者的三个攻击技能分别使自身失去7、10、15点理智，并全部使用负硬币。理智越低，反面概率越高，负硬币技能越接近最高表现。

原版还故意让通常的战斗奖励与角色需求冲突：

- 拼点胜利和击杀敌人会恢复理智，反而使负硬币变得不稳定。
- 战斗被动把拼点胜利和击杀带来的理智恢复减少50%。
- 守备“够了……”恢复5至10理智，是接近失控时的主动刹车。
- 一技能反面命中使自身获得狂信，二、三技能读取自身狂信获得增伤。
- 三技能一次失去15理智，是强力攻击，也是最容易越过失控线的技能。

原版要求玩家主动让辛克莱越来越不正常，同时避免他真的崩溃。甚至战斗打得太顺、拼点赢得太多，也会破坏他的理想状态。

### 2. 直接保留的内容

- 三个攻击技能的名称得到保留。
- “自我毁灭的净化”仍是最强、也最危险的攻击。
- 力量与精神失控绑定。
- 玩家需要停留在临界值附近，而不是无脑把资源叠满。
- 守备仍然承担主动退出危险区的作用。
- 越过极限后会失去对攻击目标的正常控制。

### 3. 为《零境交错》重新设计的内容

| 原版 | 当前版本 |
| --- | --- |
| 负理智越深，负硬币越稳定 | SAN越高，最终伤害越高 |
| 三个技能分别主动失去理智 | 终结技增加SAN，普通技能建立团队目标 |
| 拼点和击杀恢复理智 | 本人行动结束后固定降低10 SAN |
| 自身狂信强化后续技能 | 敌方狂信被队友逐段消耗并转化为SAN |
| 三技能是牌库中的稀有强力技能 | 三技能成为动态费用终结技 |
| 接近负理智极限时可能失控 | 达到45后必须攻击一次自己人 |

当前版本没有复制负硬币概率，而是用动态伤害档位和终结技费用制造相同的诱惑。它保留了“接近失控才能最强”的行为，却把主要操作从个人理智管理扩展成全队的攻击频率、行动顺序和站位管理。

### 4. 玩家行为的变化

原版玩家主要在控制辛克莱自己：

> 继续使用技能降低理智，压制理智恢复，在接近失控时使用守备刹车。

当前版本玩家主要在组织整个队伍：

> 辛克莱标记净化目标，队友按合适的频率消耗标记，把他推到理想SAN，再决定是否越过45。

原版更个人、更概率化，也更强调自我毁灭；当前版本更团队、更确定，也更强调技能点、升华点、攻击段数和前中后排。

## 九、设计优点

### 1. 保留行为而不是照搬系统

当前游戏没有负硬币和原版拼点理智循环，因此没有强行复制无法成立的表面机制。动态伤害、动态费用和侵蚀友伤重新制造了相同的心理诱惑。

### 2. 一条资源承担完整循环

SAN同时决定伤害、终结技费用、侵蚀风险、守备需求和队友出手节奏。各项被动围绕同一个核心工作，没有再增加无关资源。

### 3. 风险被设计成实际行为

达到45后必须攻击一次队友，比单纯扣血、扣属性或受到反噬更有辨识度。它改变玩家接下来必须做的事情，也让站位和技能目标规则参与止损。

### 4. 第一回合直接展示核心

初始40让玩家无需机械启动，第一次行动就能看到0费大招、最高增伤与侵蚀代价。角色的优势和危险不会被藏在数回合之后。

### 5. 有限层数区分兑现速度

狂信按段数消耗，但总收益由层数决定。高频角色负责快速兑现，低频角色负责保留调整空间，不会因为未来角色段数增加而无限放大收益上限。

### 6. 敌我双方都能进入资源判断

队友攻击狂信目标提高SAN，狂信目标攻击辛克莱也能提高SAN。队友攻击段数、敌人攻击频率和辛克莱站位共同影响循环。

### 7. 原版细节进行了有效删减

烧伤、流血、机械融合生命体特攻和N公司人数条件没有被强行搬入。删除这些构筑细节以后，角色仍然保留准执柄者最关键的失控体验。

### 8. Main与Sub边界清楚

护援技保持简单独立，不要求辛克莱位于Sub位置时继续运行Main的SAN完整循环，避免护援技能抢占主战角色玩法。

## 十、缺点与风险

### 1. 一、二技能在SAN循环中的差异较小

原版三个技能分别失去不同理智，每个攻击按钮都在决定精神下沉速度。当前一、二技能都主要通过净化异端施加1层狂信，两者在核心资源中的作用相近。

玩家选择一、二技能时主要比较费用、范围和倍率，而不是选择不同的SAN管理强度。核心玩法更多集中在被动、队友和终结技上。

### 2. 高SAN同时获得两项最高收益

40至45 SAN同时提供50%最终增伤和0费终结技。如果一次侵蚀友伤的实际损失不足，第一回合开大可能从危险选择退化为固定最优解。

需要分别评价：

- 0费大招带来的伤害与升华点收益。
- 侵蚀攻击对队伍造成的真实损失。
- 玩家能否通过站位轻易把侵蚀代价转移给几乎不受影响的目标。

### 3. 精确区间存在信息负担

SAN同时具有多个伤害档位、终结技费用档位和狂信施加档位。若界面只显示当前SAN数字，玩家需要频繁查表才能判断收益。

战斗界面应明确显示：

- 当前最终伤害修正。
- 当前终结技费用。
- 本次终结技预计增加的SAN。
- 本次终结技预计施加的狂信层数。
- 是否将在结算后达到45并进入侵蚀。

### 4. 初始40改变了原版的下沉过程

原版从正常理智逐步下降，玩家观看辛克莱越来越接近崩溃；当前版本开局已经处于最高档位附近，把这段过程压缩成第一回合的立即选择。

它解决了启动手感，也强化了开局辨识度，但牺牲了一部分逐渐失控的过程感。

### 5. 团队推动削弱个人自毁感

原版主要由辛克莱自己的三个攻击技能降低理智；当前版本除终结技外，SAN主要由队友和敌人的攻击段数推动。

这让玩法更适合团队制《零境交错》，但也把“辛克莱亲手毁掉自己”改变成“整支队伍把辛克莱推向狂热”。两者都能成立，但表达重点并不相同。

### 6. 狂信名称与实际对象不符

当前状态施加在被净化的敌人身上，却沿用原版自身BUFF“狂信”的名称。玩家可能误解为敌人获得了狂信状态。后续应只修正文案名称，不需要因此推翻机制。

### 7. 多种安全手段可能降低失控感

行动结束降低10、守备降低5、“够了……”不能达到45，再加上玩家可以控制攻击段数和站位，辛克莱拥有较多控制侵蚀的方法。

这些规则分别都有作用，但需要观察实际游玩中是否会让危险循环变成稳定可解的固定算术。可控性应该帮助玩家承担风险，而不应让侵蚀长期只存在于文本中。

## 十一、设计意图分析

### 1. 基本可以确定

- 由于BUFF系统不能使用负数，因此把原版负理智反向表现为0至45的正数SAN。
- 由于当前战斗没有负硬币拼点，因此用动态最终伤害表现低理智带来的高输出。
- 将原版三技能提升为终结技，以适配一技能、二技能、终结技的角色结构。
- 用动态升华点费用承接原版“越接近失控，技能表现越高”的收益。
- 用强制攻击队友把原版失控转化成可见、可承受、可通过站位止损的实际后果。
- 初始40用于避免启动期，让玩家第一回合立即接触角色核心。

### 2. 较可能的意图

- 把原版自身狂信扩展成团队净化目标，使队友攻击也能进入辛克莱循环。
- 用逐段消耗让高频与低频角色获得不同的配队意义，但不改变有限狂信的总收益。
- 让敌人的攻击段数和前中后排标签也参与SAN管理，提高角色对关卡的研究空间。
- 保留守备刹车，但把原版恢复理智改成降低正向SAN，以适配数值方向反转。
- 删除烧伤、流血等原版构筑细节，避免它们分散失控主轴。

## 十二、值得学习的设计方法

### 1. 移植玩家行为，而不是移植名词

原版系统无法直接复制时，应先确认玩家原本在做什么，再用本作机制重新制造相同的欲望、风险和后果。

### 2. 让同一资源连接收益与代价

SAN既提供伤害和低费用，也通往侵蚀。资源越高并不意味着越正确，玩家需要主动决定停在哪里。

### 3. 将惩罚设计成行为债务

强制友伤会改变后续行动、技能选择与站位安排，比普通反噬数值更能塑造角色。

### 4. 用有限层数控制逐段触发

每段攻击只负责消耗已有层数，使攻击频率改变兑现速度而不扩大总收益。这能区分高频与低频角色，同时避免段数自然形成无限增幅。

### 5. 让第一回合交付角色核心

无须启动不等于没有风险。可以把力量直接交给玩家，再用明确的后果决定玩家是否立即使用。

### 6. 优先使用本作已有决策维度

技能点、升华点、守备、攻击段数、行动顺序和前中后排都已经存在。角色深度来自重新组织这些系统，而不是不断新增独立操作界面。

### 7. 删除不能服务核心的原版细节

原版状态、阵营条件和特攻不需要全部出现。角色还原的标准应是玩家是否做出了符合人物的行为，而不是技能文本是否保留了最多名词。

### 8. 护援技不必复刻Main循环

护援技只服务Sub位置，应保持独立可用，不需要为了形式统一强行携带SAN的完整产生与消耗流程。

## 十三、不宜直接照搬的部分

### 1. 不要把危险资源条做成角色通用模板

SAN适合准执柄者，是因为精神失控本来就是这个人格的核心。其他角色不能只换一个资源名称就复制接近上限、获得增伤、满层失控的结构。

### 2. 不要普遍让被动承担全部玩法

如果主动技能只负责倍率，而所有特色都藏在被动触发中，玩家可能无法从技能选择直接感受到角色差异。

### 3. 不要无条件叠加最高伤害与最低费用

同一档位同时获得多项顶级收益时，必须存在足够真实的机会成本，否则危险选择会变成固定答案。

### 4. 不要把强制友伤当作普通反噬模板

友伤在准执柄者身上来源明确，也有侵蚀依据。缺少人物依据的角色使用相同惩罚，只会显得刻意。

### 5. 不要把所有角色都扩展成全队发动机

当前版本将个人理智循环扩展到队友段数，是针对团队制战斗的改造。其他角色是否需要读取全队行动，必须由人物行为和本体机制共同决定。

### 6. 不要为了保留原作名词牺牲文本准确性

当状态对象和含义已经改变时，应当重新命名。保留错误名词不会提高还原度，只会增加理解成本。

### 7. 不要把可研究性变成查表负担

多档位资源必须提供清楚的界面反馈。玩家应该研究队伍与行动顺序，而不是反复背诵区间数字。

## 十四、总结

辛克莱【准执柄者】的核心不是一条SAN资源，也不是0费终结技，而是让玩家长期停留在“再多一点就会失控，但现在停下太可惜”的状态。

原版通过负硬币、主动失去理智、压制理智恢复和守备回血制造这种行为；当前版本则通过动态增伤、动态终结技费用、有限狂信、队友攻击段数和侵蚀友伤重新实现它。

这次改编最成功的地方，是没有照搬原版无法成立的硬币系统，而是保留了力量与失控之间的诱惑关系。最需要继续观察的地方，是一、二技能与SAN循环的联系、高SAN双重收益是否形成固定答案，以及侵蚀代价在实际战斗中是否足够真实。

角色最终要求玩家做的不是简单攒满资源，而是组织全队把辛克莱推到最危险的位置，并准确决定最后一段攻击是否应该发生。
