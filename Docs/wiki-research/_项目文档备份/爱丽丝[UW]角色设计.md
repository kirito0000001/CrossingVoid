# 爱丽丝[UW]角色设计

> 本文集中记录爱丽丝【UW】的技能资料、实际玩法、设计评价、设计意图和可复用经验。技能资料来自现有角色介绍图；资源消耗、护援技定位等容易误读的部分，以设计者后续确认的规则为准。

## 一、角色设计概览

### 1. 基础定位

- 速度值：520
- 全属性T
- 异能爆发
- 低耗费

“全属性T”是游戏中的公共战术定位，表示角色可以对策敌方的前排、中排和后排攻击，并不是爱丽丝独有的角色特色。当前版本的爱丽丝也没有嘲讽，不能改变敌方的攻击目标；嘲讽机制留待其他角色使用。

因此，分析爱丽丝时需要分开看待：

- **公共定位**：全属性T、异能爆发、低耗费。
- **专属玩法**：积累和转化金桂绽放。
- **原作表现**：解放金桂之剑，并决定花瓣用于防御还是进攻。

### 2. 核心体验

爱丽丝围绕同一个专属资源完成积累、技能变化、攻防分岔与清空：

> 骑士之击积累金桂绽放 → 3层时进入攻防分岔 → 转化为防御架势，或使用金桂飞舞达到5层 → 通过终结技转化为金桂绽放术式 → 全部清空后重新积累

她的核心不是单纯叠满层数，而是在关键节点决定已经解放的金桂花瓣要用来做什么。

## 二、被动：武装完全支配术-记忆解放

当 **金桂绽放** 达到3层及以上时，一技能由 **骑士之击** 切换为 **金桂飞舞**。

技能替换后发生的变化包括：

- 0费变为3费。
- 前中排攻击变为群体攻击。
- 物理伤害变为异能伤害。
- 反击守备变为防御守备。
- 技能结束获得1层金桂绽放，变为获得2层。

因此，记忆解放不是简单的倍率强化，而是让爱丽丝从普通剑击进入以金桂花瓣为主体的战斗方式。

## 三、技能资料

### 1. 一技能：骑士之击

| 项目 | 内容 |
| --- | --- |
| 费用 | 0技能点 |
| 目标 | 前中排攻击 |
| 守备 | 反击（80%） |
| 物理倍率 | 36% / 90% / 150% / 258% / 348% |
| 异能倍率 | 无 |
| 特殊效果 | 技能结束时，自身获得1层金桂绽放 |

骑士之击是普通阶段的主要积累手段。它不消耗技能点，也不会通过基础规则产生升华点。

### 2. 强化一技能：金桂飞舞

| 项目 | 内容 |
| --- | --- |
| 费用 | 3技能点 |
| 目标 | 群体攻击 |
| 守备 | 防御（50%） |
| 物理倍率 | 无 |
| 异能倍率 | 72% / 180% / 270% / 360% / 468% |
| 特殊效果 | 技能结束时，自身获得2层金桂绽放 |

当金桂绽放达到3层时，骑士之击被替换为金桂飞舞。正常情况下，3层使用金桂飞舞后会直接达到5层上限。

### 3. 二技能：金桂加护

| 项目 | 内容 |
| --- | --- |
| 费用 | 0技能点 |
| 目标 | 自身护盾类技能 |
| 守备 | 防御（80%） |
| 物理倍率 | 无 |
| 异能倍率 | 无 |
| 特殊效果 | 移除自身全部金桂绽放，并根据移除前的层数获得同等级防御架势，最多获得3级 |

图片中的“最多消耗3层”容易被理解为只移除3层、保留剩余层数。实际结算是 **无论当前有多少层都会全部清空**，只是防御架势最高只能达到3级。

因此，5层时使用金桂加护也会清空全部5层，却仍然只能获得3级防御架势。

### 4. 护援技：斜斩

| 项目 | 内容 |
| --- | --- |
| 费用 | 0技能点 |
| 目标 | 前排攻击 |
| 守备 | 防御（50%） |
| 物理倍率 | 120% / 200% / 300% / 480% / 660% |
| 异能倍率 | 无 |
| 特殊效果 | 无 |

护援技只在爱丽丝位于Sub位置时使用，不属于她作为主战角色时的金桂绽放循环。详细评价见“护援技的设计边界”。

### 5. 终结技：旋转吧，花瓣们！

| 项目 | 内容 |
| --- | --- |
| 费用 | 13升华点 |
| 目标 | 群体攻击 |
| 守备 | 防御（50%） |
| 物理倍率 | 无 |
| 异能倍率 | 150% / 250% / 600% / 850% / 1200% |
| 特殊效果 | 技能释放前，移除全部金桂绽放，并根据移除前的层数获得同等级金桂绽放术式 |

终结技会清空全部金桂绽放。当前层数越高，本次终结技获得的最终伤害加成越高。

## 四、特殊效果

| 效果 | 最大值 | 持续时间 | 作用 |
| --- | ---: | ---: | --- |
| 金桂绽放 | 5 | 无限 | 爱丽丝的专属BUFF，改变技能形态和强度 |
| 防御架势 | 3 | 3 | 根据等级使受到的最终伤害降低10% / 30% / 50% |
| 金桂绽放术式 | 5 | 1 | 根据等级使造成的最终伤害增加2% / 4% / 8% / 10% / 20% |

### 1. 防御架势

防御架势只有最终伤害减免效果，不会额外生成一层独立护盾。金桂加护本身带有防御守备，但防御架势与公共守备值是两套不同结算。

### 2. 金桂绽放术式

终结技释放前会将全部金桂绽放转化为同等级术式，并用于强化本次爆发。5级术式提供20%最终伤害加成，明显高于其他等级，因此进攻路线强烈鼓励满层释放终结技。

### 3. 当前不可达的4层

爱丽丝自身正常产生金桂绽放的路径是：

> 0 → 1 → 2 → 3 → 5 → 0

骑士之击每次增加1层；达到3层后一技能切换为金桂飞舞，并一次增加2层。因此，当前技能组无法自然到达4层，金桂绽放术式的4级10%加成属于不可触发的数值档位。

设计者确认这是早期设计时没有注意到的状态路径遗漏。

## 五、实际玩法

### 1. 准备阶段

爱丽丝使用0费骑士之击攻击前中排，并逐步获得金桂绽放。这个阶段几乎不占用队伍技能点，但0费技能也不会通过基础资源规则生成升华点。

### 2. 3层攻防分岔

金桂绽放达到3层后，玩家面临核心选择。

#### 防御路线

使用金桂加护，清空全部金桂绽放并获得3级防御架势，在3回合内减少50%最终伤害。选择防御意味着放弃当前积累的进攻进度，随后重新从0层开始。

金桂加护也可以在1层或2层时提前使用，分别获得较低等级的防御架势。这样能够更早应对危险，但资源转化效率和减伤幅度也更低。

#### 进攻路线

继续使用替换后的一技能金桂飞舞，消耗3技能点发动异能群攻，并由3层直接达到5层。随后释放13升华点终结技，把5层全部转化为20%最终伤害加成，完成群体爆发。

### 3. 允许反悔，但需要付出代价

达到5层后，玩家仍然可以临时改用金桂加护保命。但5层会被全部清空，而防御架势最高只读取3层，多出的2层不会保留，也不会产生额外防御收益。

这使爱丽丝在选择金桂飞舞后仍有紧急止损手段，但不能无代价地在进攻与防御之间横跳。

### 4. 队伍资源关系

爱丽丝的准备技能和防御技能都是0费，因此平时会把技能点留给队友；但她自己也很少通过普通技能产生升华点。金桂飞舞只能提供3点基础升华收益，终结技却需要13点升华点。

因此，她的“低耗费”主要表示准备阶段不争夺队伍资源，并不表示她能够独立快速完成终结技循环。完整爆发仍然依赖队友使用普通技能生产升华点。

## 六、设计优点

### 1. 一个资源承担完整玩法

金桂绽放同时记录解放进度、控制技能替换，并作为防御架势与终结技术式的转化材料。所有功能都来自如何调度金桂花瓣，没有为攻击、防御和变身分别增加三套资源。

### 2. 资源拥有完整生命周期

金桂绽放会产生、达到阈值、改变技能、被选择用途、全部消耗并重新积累。它不是只会逐渐增大的被动计数器，而是会真正离开玩家手中的战斗资源。

### 3. 技能替换改变实际行为

骑士之击变为金桂飞舞以后，费用、目标、伤害类型、守备方式和资源产量全部改变。玩家能够从操作上感到武装完全支配术已经解放，而不是只看到同一技能增加倍率。

### 4. 攻防分支来自同一种原作能力

金桂花瓣既能形成防御架势，也能投入大范围攻击。全套攻防机制都围绕金桂之剑展开，因此两种用途不会像互不相关的坦克技能与爆发技能被强行拼在一起。

### 5. 关键决策点非常清楚

3层是明确的攻防分岔：现在把花瓣全部转为防御，还是继续解放到5层完成爆发。玩家不需要每回合处理许多细小规则，却会记住这个角色最重要的决定。

### 6. 资源费用与演出规模同步增长

普通剑击0费，金桂飞舞3费，最终术式13升华点。随着金桂之剑逐步解放，技能费用、攻击范围和演出规模一起上升，形成从克制剑击到大规模花瓣术式的过程。

### 7. 允许紧急改变计划

5层仍可全部转入防御，使玩家不会因为此前选择进攻就彻底失去保命能力；但溢出的两层没有收益，反悔需要承担明确代价。

## 七、缺点与风险

### 1. 进攻路线容易形成固定连段

不需要防守时，最自然的路线几乎固定为骑士之击达到3层、金桂飞舞达到5层、满层释放终结技。5级术式又从4级的10%跃升至20%，进一步强化了“非满层不开大”的倾向。

循环清晰是优点，但也意味着爱丽丝在纯进攻环境中的临场变化较少。

### 2. 存在不可达的效果档位

4层术式写入了完整数值表，却无法由当前技能组自然触发。这不会破坏主要循环，但说明设计效果表以后还需要反向检查所有可能的状态路径。

### 3. 技能文本与实际结算容易产生误读

金桂加护原文本的“最多消耗3层”无法准确表达“清空全部层数，但最多获得3级防御架势”。如果玩家在5层使用，很容易错误预期会保留2层。

机制复杂并非问题，但消耗、读取上限和剩余资源必须分别写清楚。

### 4. 低耗费伴随队伍依赖

大量0费技能让爱丽丝能够给队友让出技能点，也意味着她自己很少生产升华点。13费终结技需要队友共同供给资源，队伍构成和战斗长度会明显影响她能否完成爆发。

这是可以成立的队伍定位，但不能把“0费技能很多”直接理解成角色能够独立高速循环。

### 5. 护援技的角色辨识度较弱

斜斩作为0费前排物理攻击，使用简单、兼容性好，但没有特别鲜明的爱丽丝风味。设计者也确认这个技能在早期没有经过太多展开。

问题不在于它没有接入金桂绽放，而在于它作为独立护援动作仍然比较普通。

## 八、护援技的设计边界

### 1. 护援技不是主战循环的一部分

爱丽丝只有位于Sub位置时才会使用斜斩。此时玩家实际围绕当前主战角色行动，不会运行爱丽丝主战状态下的完整金桂绽放循环。

因此，不能用“是否参与金桂绽放的产生与消耗”评价斜斩。强行让护援技展开武装完全支配术，反而可能在同一回合中要求玩家管理两套专属资源，抢占主战角色的玩法空间。

### 2. 护援技应当完成的任务

一个合适的护援技应当：

- 脱离本体循环也能独立使用。
- 不要求提前积累Sub角色的专属状态。
- 功能明确，不抢占主战角色的决策重心。
- 能够与多种主战角色组合，而非只服务自身本体。
- 在保持简洁的同时，尽可能留下角色辨识度。

### 3. 对斜斩的准确评价

斜斩的简单并不是结构缺陷。0费、前排攻击和防御守备使它容易插入不同主战角色的行动，不会额外制造资源负担。

它的不足只是风味与用途较为普通，没有充分利用一次短暂登场表现爱丽丝作为整合骑士的特点。这属于独立技能位仍有塑造空间，不代表它应该接入金桂绽放循环。

### 4. 可以提炼的原则

不是角色身上的所有技能都必须围绕同一套玩法。设计前需要先确认技能由谁使用、角色处于什么位置，以及它是否会与当前主战角色争夺注意力。

主战技能负责让玩家完整扮演爱丽丝；护援技只需要让玩家感到爱丽丝从Sub位置提供了一次属于她的帮助。两种技能的设计密度本来就可以不同。

## 九、设计意图分析

设计者确认以下整体判断基本符合原意：

- 用技能替换表现武装完全支配术真正改变了爱丽丝的战斗方式。
- 用物理伤害转为异能伤害，区分普通剑击与金桂花瓣攻击。
- 让同一批花瓣可以全部转为防御，也可以继续解放并投入终结技。
- 用0费准备和13费终结技制造平时克制、完全解放时壮观的反差。
- 让玩家实际调度金桂之剑，而不是只观看爱丽丝自动完成招式。
- 3层到5层的精确衔接，用于构成清楚、完整的武装解放流程。

需要单独说明的是：

- 全属性T属于公共战术定位，不能作为爱丽丝的独有性格或能力解释。
- 当前爱丽丝没有嘲讽，不能主动把攻击转移到自己身上。
- 4层术式不可达并非刻意设计，而是早期制作时遗漏了状态路径检查。
- 护援技斜斩设计得较简单，并非刻意建立另一套Sub玩法。

## 十、值得学习的设计方法

### 1. 用一个来源明确的资源完成多项职责

资源可以同时承担进度、形态和消耗材料，但前提是这些职责都来自同一个原作对象。爱丽丝管理的是金桂花瓣，而不是三个为了玩法复杂度临时创造的数值条。

### 2. 为资源设计产生、变化、消耗与重置

完整资源循环不仅要说明如何获得和叠高，还要说明何时改变技能、如何花掉、清空后如何重新开始。只有存在真实消耗，玩家才会认真判断使用时机。

### 3. 让技能强化改变选择理由

好的技能替换应改变费用、目标、伤害类型或用途，使玩家在形态变化后重新判断行动，而不只是继续按同一个按钮获得更高倍率。

### 4. 用同一能力连接双定位

攻击与防御不必各自拥有一套无关机制。只要原作能力本身支持多种用途，就可以让玩家决定同一资源最终服务哪个方向。

### 5. 把核心决策集中在少数关键节点

不是每个角色都需要每回合进行复杂计算。一个清楚、有代价的分岔点，也能建立足够鲜明的玩法记忆。

### 6. 允许玩家止损，但保留机会成本

角色可以允许玩家在紧急情况下改变路线，避免一次决定导致整场战斗失去操作空间；同时应让反悔损失部分效率，维持前一次选择的意义。

### 7. 尊重主战与Sub位置的技能边界

主战角色的专属循环不应自动延伸到护援技。护援技首先需要独立、兼容和简洁，再考虑如何用一个短动作留下角色风味。

## 十一、不宜直接照搬的部分

### 1. 不要把叠层和技能替换当作万能模板

爱丽丝适合这套结构，是因为金桂之剑确实存在记忆解放、花瓣展开和攻防调度。其他角色若没有相应原作依据，不应为了制造玩法而强行添加五层资源。

### 2. 不要先填满效果表，再假设所有档位都能触发

写完层数效果后，应实际推演角色的所有状态路径，确认每个档位是否可达、是否有合理使用场景。

### 3. 不要用模糊文本隐藏消耗规则

“全部移除”“最多读取几层”“超过上限是否浪费”应分别说明。玩家可以接受代价严厉，但不能接受结果与技能文本不同。

### 4. 不要让清晰循环无条件退化为固定连段

封闭循环适合表现完整术式，但并不适合所有角色。若角色的原作战斗风格强调临场应变，就需要更多能够改变路线的条件，而不是简单复刻爱丽丝的3层分岔与5层收束。

### 5. 不要用公共定位代替角色塑造

主C、T、前中后排攻击等标签只能说明游戏用途。移除这些公共标签后，角色剩余的机制仍然应该能够指向原作中的这个人。

### 6. 不要强迫护援技复刻本体循环

护援技需要服务当前主战角色所在的组合。让Sub角色携带一套完整的专属资源，往往会增加认知负担并抢走主战玩法。简单并非缺点，缺乏明确用途或角色风味才是需要改进的部分。

## 十二、总结

爱丽丝最值得保留的设计核心是：

> 用金桂绽放这一种专属资源，完成普通剑击、记忆解放、技能替换、攻防分岔、完全绽放和最终清空。

她让玩家管理的不是抽象层数，而是金桂之剑已经解放的花瓣。玩家在3层决定将其全部用于防御，或继续达到5层投入终结技，这一行为就是角色辨识度的主要来源。

她最需要警惕的不是机制不够多，而是固定进攻路线、不可达的4层以及文字未能准确表达全部消耗。护援技则应独立评价：不需要接入金桂绽放循环，但可以在保持简洁的前提下拥有更鲜明的爱丽丝风味。
