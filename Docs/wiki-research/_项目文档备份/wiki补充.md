# Wiki补充

> 本文整理当前版本的局内界面、公共资源、守备与技能丢弃规则。角色自身的技能组、玩法分析和设计评价改为分别记录在对应的角色设计文档中。若后续实装规则发生变化，应以游戏内最新文本和实测结果为准。

## 一、局内战斗界面：同步指示器

进入战斗后，点击角色头像可以打开该角色的详细信息。这个界面不是单纯的属性面板，而是查看技能、被动和当前状态的主要入口。

### 1. 角色信息区域

- **左侧**：显示技能等级。技能等级来自局外养成，会影响技能倍率。
- **中间**：显示当前血量、攻击力、守备值、角色名称与连携状况。
- **右侧**：显示被动技能及其说明。

### 2. 顶部页签

- 切换到 **特殊效果** 后，可以点击BUFF图标查看名称、层数、持续时间与具体效果。
- 切换到 **技能** 后，可以查看各技能的伤害倍率、特殊效果、目标位置和守备类型。

遇到“不知道为什么伤害变化”“角色为什么没有被命中”“某个技能为什么进入另一形态”等情况时，应优先检查特殊效果和被动，而不是只看技能盘上的简短标签。

## 二、技能点与升华点

技能盘下方有两种公共战斗资源：

- **技能点**：蓝色，用于释放普通技能。
- **升华点**：金色，用于释放终结技。

### 1. 基础资源循环

1. 每次行动开始时，当前行动的角色组合获得2点技能点。
2. 释放普通技能时，消耗技能标注的技能点。
3. 普通技能结算后，获得与技能点消耗量相同的升华点。
4. 升华点达到终结技要求后，可以释放对应终结技。

因此，高费用技能不只是威力更高，也是在更快地把技能点转换成升华点；低费用技能则更适合维持技能点、补充状态或等待下一次行动。部分技能还会额外恢复技能点或升华点，这些效果会改变通常的资源收支。

### 2. 目标与站位

技能会标注前排、中排、后排或群体目标。实际目标根据双方当前站位Tag判断，而不是永远锁定某一名固定角色。

前、中、后排Tag会随着角色死亡和阵容空缺重新分配。例如，原前排不存在或死亡后，当前最靠前的中排或后排会获得前排Tag，后续前排技能就会以该角色为目标；其他位置同样按照当前存活阵容重新判断。因此，“后排死亡后改为攻击中排”通常不是某个角色的专属追踪机制，而是所有站位技能共同遵循的底层目标规则。

阅读技能时，需要同时确认：

- 攻击哪个位置。
- 是单体、群体还是全体效果。
- 当前站位变化后，目标是否会改变。
- 技能是造成伤害，还是施加增益、减益或其他特殊效果。

## 三、守备与技能丢弃

新版战斗加入了守备机制。右键技能，或在触屏设备上长按技能，可以给该技能添加丢弃标记。

丢弃标记的颜色对应守备类型：

| 标记颜色 | 守备类型 | 主要作用 |
| --- | --- | --- |
| 橙色 | 防御 | 生成守备值，抵消后续伤害 |
| 紫色 | 反击 | 抵消伤害，并可能向攻击方追加攻击 |
| 白色 | 闪避 | 按标注次数令攻击无法命中 |

正常释放技能和丢弃技能时都会生成守备，但两者不是同时结算攻击与守备：

- 正常释放时，结算技能原本的攻击与特殊效果，并生成该技能标注的基础守备。
- 丢弃后，技能原本的攻击与特殊效果不再结算，只执行守备，并获得更高的守备值或更多闪避次数。
- 个别技能可以另行带有“作为守备使用时才触发”的效果。这类效果属于技能的明确例外，不代表被丢弃的原技能仍会照常结算。

行动结束后，尚未消耗的守备值不会自动清零，而会继续保留；角色下一次释放技能时，守备值会跟随新技能重新刷新。

### 1. 防御

进入防御守备后，血条上会出现绿色守备进度条。

- 正常释放：按照角色血量上限的18%生成总守备值。
- 丢弃技能：按照角色血量上限的36%生成总守备值。

技能标签中“防御”后的百分比，表示总守备值中物理守备所占的比例，其余部分为异能守备。

例如，技能标注“防御（70%）”，角色本次共生成100点守备值，则其中70点用于承受物理伤害，30点用于承受异能伤害。这不是“减伤70%”。

只要物理守备或异能守备中的任意一种被完全打空，角色就会退出本次守备状态。因此，面对连续的同属性攻击时，即使另一种守备仍有剩余，也不能继续依靠它维持防御。

### 2. 反击

进入反击守备后，血条上会出现深蓝色守备进度条。

- 正常释放：按照角色血量上限的5%生成守备值。
- 丢弃技能：按照角色血量上限的10%生成守备值。

反击的承伤部分通常可以按防御理解，但基础守备量更低；其额外价值是抵消伤害后追加攻击。

当攻击方与被攻击方都处于反击守备时，会进入拼刀。现阶段说明可以确认：

1. 由被攻击角色的抗性决定本次拼刀使用的属性类型。
2. 比较双方对应的守备值。
3. 守备值更高的一方胜出。
4. 当前血量越低，反击造成的伤害倍率和击飞力度越高。

反击与拼刀的完整流程、伤害倍率及击飞计算仍待后续资料补充。在这些规则确认前，不继续推断更具体的操作结论。

### 3. 闪避

进入闪避守备后，血条上会出现白色守备进度条。

- 技能会直接标注可闪避次数，例如“闪避（3）”。
- 丢弃该技能后，闪避次数翻倍；“闪避（3）”会提高为6次。

闪避按次数工作，不使用血量百分比计算。面对少量高伤害攻击时，闪避可能比护盾更有效；面对大量多段攻击时，则需要确认剩余闪避次数是否足够。

### 4. 为什么守备和速度是通关核心

守备让技能不再只有“释放哪个伤害更高”这一种选择。玩家还需要判断：

- 当前技能应该正常释放，还是换取更高守备。
- 对方即将造成物理伤害还是异能伤害。
- 应该用防御承受、用反击争夺主动权，还是用闪避完全避开。
- 是否需要先控制速度，改变攻击顺序和拼刀关系。

合理使用守备与控速，可以处理大部分只靠堆伤害难以通过的关卡。
