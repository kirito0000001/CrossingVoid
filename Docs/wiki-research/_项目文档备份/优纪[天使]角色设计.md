# 优纪[天使]角色设计

> 本文集中记录优纪【天使】的技能资料、残心循环、终结技超额支付、天使队判定、设计评价与可复用经验。该版本与原作关系较弱，主要用于记录一次偏原创的多方向机制尝试。所有费用、BUFF时点和Main/Sub边界以设计者后续确认的规则为准。

## 一、角色设计概览

### 1. 基础定位

- 速度值：820
- 异能抗性
- 双属性C
- 前排攻击
- 暴击伤害
- 闪避守备
- 天使队核心

### 2. 核心体验

优纪【天使】以残心完成一套准备、转换、爆发和退出的形态循环：

`常态技能获得残心 → 终结技将残心转换为残心宣叙 → 进入残心流 → 一、二技能按不同速度消耗宣叙 → 宣叙归零后退出残心流`

常态阶段负责准备资源和全队升华点，终结技负责启动形态并立即兑现本次爆发，残心流阶段则由强化二技能承担主要输出，一技能负责低成本调整剩余层数。

角色同时具有天使阵营玩法。全体Main属于天使时，优纪为自己和天使队友提供光环；位于Sub时，她还能通过护援技把当前Main临时转化为天使，弥补早期天使角色数量不足。

这套设计的个人主轴是残心流，终结技超额支付是形态入口，天使队是编成外壳，种族特攻则是附带对策。

## 二、残心与残心宣叙

### 1. 残心

| 项目   | 内容                |
| ---- | ----------------- |
| 最大层数 | 11层               |
| 持续时间 | 无限                |
| 主要来源 | 常态一、二技能成功释放时各获得5层 |
| 主要用途 | 被终结技全部转换为残心宣叙     |

残心本身不直接提供伤害属性，它是进入残心流前的准备资源。常态一、二技能都稳定获得5层，使玩家不需要执行固定技能顺序：

- 任意两次常态技能即可得到10层。
- 玩家可以直接以10层进入完整循环。
- 若行动顺序和升华点准备允许，可以再通过0费一技能补到11层。

上限11对应圣母圣咏的十一连击，但它不是每轮必须完成的强制目标。10层和11层都可以自然完成三次强化二技能，11层主要提供额外一层暴击属性和角色数字风味。

### 2. 残心宣叙

| 项目   | 内容                |
| ---- | ----------------- |
| 最大层数 | 11层               |
| 持续时间 | 无限                |
| 每层效果 | 暴击率提高3%，暴击伤害提高11% |
| 退出条件 | 全部层数被消耗后退出残心流     |

终结技把当前全部残心转换成等量残心宣叙。转换发生在本次终结技伤害结算前，因此本次终结技立即获得宣叙提供的暴击属性。

典型属性为：

| 宣叙层数 | 暴击率  | 暴击伤害  |
| ----:| ----:| -----:|
| 10层  | +30% | +110% |
| 11层  | +33% | +121% |

残心宣叙既是当前暴击强度，也是残心流剩余寿命。技能消耗宣叙后，后续攻击的暴击属性会逐步下降；但本次攻击先使用消耗前的完整层数，攻击结算结束后才扣除宣叙。

### 3. 两种消耗速度

- 一技能在残心流中消耗1层残心宣叙。
- 强化二技能在释放结束时消耗4层或全部剩余层数。

两者承担不同职责：

- 一技能0费，适合低成本调整和延长形态。
- 强化二技能4费，是残心流的主要输出，负责高效占用行动回合并快速兑现宣叙。

当剩余宣叙不足4层时，强化二技能会消耗所有剩余层数，不要求玩家先用其他技能补足4层，也不会因为资源不足而无法释放。

连续使用强化二技能时：

- 10层的消耗过程为`10 → 6 → 2 → 0`。
- 11层的消耗过程为`11 → 7 → 3 → 0`。

两种起点都能自然完成三次强化二技能并退出形态，没有难以清理的残余层数。

## 三、其他特殊效果

### 1. 绝剑

| 项目   | 内容           |
| ---- | ------------ |
| 最大层数 | 1层           |
| 持续时间 | 1            |
| 效果   | 终结技异能伤害提高11% |

常态终结技消耗12升华点时获得绝剑；残心流中的终结技则在释放时直接获得绝剑。绝剑在伤害结算前获得，立即强化当前终结技。

### 2. 日向流

| 项目   | 内容       |
| ---- | -------- |
| 最大层数 | 4层       |
| 持续时间 | 1        |
| 每层效果 | 最终伤害提高7% |

常态终结技每额外消耗1升华点，就获得1层日向流：

- 消耗8点：0层。
- 消耗9点：1层，最终伤害提高7%。
- 消耗10点：2层，最终伤害提高14%。
- 消耗11点：3层，最终伤害提高21%。
- 消耗12点：4层，最终伤害提高28%。

日向流在本次终结技伤害前获得，并立即强化当前攻击。

### 3. 天使立场

| 项目   | 内容                 |
| ---- | ------------------ |
| 最大层数 | 1层                 |
| 持续时间 | 2                  |
| 效果   | 当前Main在两回合内被视为天使归属 |

天使立场由护援技“小天使请安”提供。全员天使条件只检查场上的Main，不检查不常驻显示的Sub；因此非天使Main携带优纪【天使】作为Sub后，可以通过护援技临时加入天使队判定。

### 4. 神圣净化

| 项目   | 内容        |
| ---- | --------- |
| 最大层数 | 1层        |
| 持续时间 | 1         |
| 效果   | 最终伤害提高20% |

当攻击目标属于恶魔、亡灵或魔物类角色时，优纪获得神圣净化。该效果在当前技能伤害前获得，并立即强化本次攻击。

### 5. 天使之力-优纪

“天使之力-优纪”在代码中通过两个BUFF分别发放，但概念上属于同一项被动的两个效果：

- 优纪【天使】自身获得10%物理防御。
- 天使侧角色获得11%最终伤害和11%暴击伤害。

代码可以继续使用两个BUFF实现，正式技能说明则应合并描述发放对象，避免玩家误以为角色拥有两个同名被动。

## 四、被动技能

### 1. 残心流

获得残心宣叙后，优纪进入残心流。残心流持续期间：

- 二技能从“日向·改”变化为“绝剑·咏叹”。
- 终结技升华点消耗固定为6点。
- 残心流终结技不再触发8至12点的超额支付。
- 释放终结技时直接获得绝剑。
- 终结技不会消耗残心宣叙。
- 残心宣叙全部消耗后，残心流结束。

由于终结技不消耗宣叙，规则上可以通过避免使用一、二技能长期维持残心流。但优纪是天使队主要输出，终结技伤害与强化二技能处于接近档位，等待队友积攒6升华点并跳过优纪自己的常规输出回合并不划算。

因此永久维持只是理论允许的非最优路线，在当前行动经济中不构成有效强度漏洞。

### 2. 天使灵装-优纪

当我方三个Main全部属于天使时：

- 优纪【天使】给自身提供10%物理防御。
- 为天使侧角色提供11%最终伤害和11%暴击伤害。

当当前目标属于恶魔、亡灵或魔物时，优纪获得1层神圣净化。

这项被动同时承担阵营光环和敌方种族对策。当前天使角色数量较少，天使立场允许其他Main临时获得天使归属，作为早期阵容未完整时的补强手段。

## 五、技能资料

### 1. 一技能：垂直四方斩

| 项目    | 内容                             |
| ----- | ------------------------------ |
| 费用    | 0技能点                           |
| 目标    | 前排攻击                           |
| 守备    | 闪避（2）                          |
| 物理倍率  | 20% / 40% / 90% / 110% / 150%  |
| 异能倍率  | 30% / 80% / 130% / 150% / 210% |
| 常态效果  | 成功释放时获得5层残心                    |
| 残心流效果 | 不再获得残心，攻击结算后消耗1层残心宣叙           |

垂直四方斩是常态阶段最低成本的残心来源，也是残心流中的细粒度消耗技能。0费让它可以在不占用技能点的情况下推进准备，但仍会占用优纪的一次行动。

### 2. 二技能：日向·改

| 项目   | 内容                               |
| ---- | -------------------------------- |
| 费用   | 4技能点                             |
| 目标   | 前排攻击                             |
| 守备   | 闪避（3）                            |
| 物理倍率 | 30% / 60% / 120% / 160% / 230%   |
| 异能倍率 | 120% / 160% / 220% / 380% / 550% |
| 特殊效果 | 成功释放时获得5层残心                      |

日向·改在常态阶段同时承担较高伤害和残心准备。它与一技能获得相同层数，使玩家可以根据技能点与当前输出需要自由选择准备方式，而不会因为资源产量不同被迫执行固定连段。

### 3. 强化二技能：绝剑·咏叹

| 项目   | 内容                               |
| ---- | -------------------------------- |
| 费用   | 4技能点                             |
| 目标   | 前排攻击                             |
| 守备   | 闪避（3）                            |
| 物理倍率 | 30% / 60% / 120% / 160% / 230%   |
| 异能倍率 | 150% / 200% / 300% / 440% / 620% |
| 特殊效果 | 攻击结算结束后消耗4层或全部剩余残心宣叙             |

绝剑·咏叹是残心流的主要输出技能。它在攻击时享受消耗前的完整宣叙暴击属性，完成伤害后才减少层数。

它与日向·改保持相同的4技能点费用，形态变化改变的是伤害、资源方向和技能用途，而不是额外提高使用门槛。

### 4. 护援技：小天使请安

| 项目   | 内容                            |
| ---- | ----------------------------- |
| 费用   | 4技能点                          |
| 目标   | 群体攻击                          |
| 守备   | 闪避（2）                         |
| 物理倍率 | 0% / 20% / 50% / 80% / 100%   |
| 异能倍率 | 20% / 60% / 90% / 140% / 170% |
| 特殊效果 | 成功释放时，当前Main获得1层天使立场          |

护援技只在优纪位于Sub时使用，不接入残心流。它的独立职责是以4费群攻为当前Main提供两回合天使归属，帮助天使队满足全体Main归属条件。

### 5. 终结技：绝剑·宣叙

| 项目    | 内容                               |
| ----- | -------------------------------- |
| 常态费用  | 基础8升华点，当前升华点超过8时强制增加消耗，最高12点     |
| 残心流费用 | 固定6升华点，不再超额支付                    |
| 目标    | 前排超度                             |
| 守备    | 闪避（5）                            |
| 物理倍率  | 50% / 120% / 300% / 420% / 480%  |
| 异能倍率  | 180% / 330% / 500% / 780% / 920% |

常态终结技的特殊效果：

1. 释放前读取我方当前升华点。
2. 拥有8点时消耗8点。
3. 拥有9至12点时强制消耗当前全部升华点。
4. 拥有超过12点时最多消耗12点。
5. 每额外消耗1点，获得1层日向流。
6. 消耗12点时额外获得1层绝剑。
7. 将全部残心转换为等量残心宣叙。
8. 日向流、绝剑和残心宣叙均立即强化本次攻击。
9. 进入残心流。

残心流终结技固定消耗6升华点，释放时直接获得绝剑，不会继续根据当前升华点超额支付，也不会消耗残心宣叙。

## 六、关键结算顺序

### 1. 常态准备

1. 优纪使用0费一技能或4费二技能。
2. 技能成功释放后获得5层残心。
3. 任意两次技能通常可以准备10层残心。
4. 玩家在准备期间同时积累全队升华点。
5. 是否补到11层取决于当前行动与升华点节奏，不是强制要求。

### 2. 常态终结技

1. 读取当前升华点并确定8至12点强制消耗量。
2. 根据超出8点的数量获得0至4层日向流。
3. 消耗12点时获得绝剑。
4. 将全部残心转换为残心宣叙。
5. 根据当前攻击目标类型判断是否获得神圣净化。
6. 日向流、绝剑、残心宣叙和神圣净化立即更新当前攻击属性。
7. 结算终结技伤害。
8. 进入残心流，二技能发生变化，终结技费用改为固定6点。

终结技在同一次技能内完成形态启动和伤害兑现，不会要求玩家等待下一次行动才能获得宣叙暴击收益。

### 3. 残心流技能

一技能：

1. 读取技能释放前的全部残心宣叙属性。
2. 结算伤害。
3. 攻击结束后消耗1层宣叙。
4. 若宣叙归零，退出残心流。

强化二技能：

1. 读取技能释放前的全部残心宣叙属性。
2. 结算主要爆发伤害。
3. 攻击结束后消耗4层；不足4层时消耗全部剩余层数。
4. 若宣叙归零，退出残心流。

残心流终结技：

1. 固定消耗6升华点。
2. 在当前伤害前获得绝剑。
3. 结算终结技伤害。
4. 不消耗残心宣叙，因此不会主动结束残心流。

## 七、完整循环的成本与收益

### 1. 准备成本

玩家通常需要优纪完成两次常态行动，取得10层残心。其中一技能0费，二技能4费且具有较高伤害；准备过程不是纯粹空转。

优纪还需要等待全队积累至少8升华点。这个等待期使额外使用一次0费一技能补到11层可以自然发生，并不等于专门浪费一回合追求象征数字。

### 2. 启动成本

常态终结技消耗8至12升华点，并会强制吞掉超过8点、最多12点的当前资源。玩家无法在拥有12点时选择只支付8点。

它的机会成本是：

- 占用全队公共升华点。
- 推迟其他角色的终结技。
- 为获得更高日向流和绝剑，需要控制全队此前的资源使用。

### 3. 即时收益

终结技不会只负责进入形态。超额支付得到的日向流、12费得到的绝剑、转换后的残心宣叙以及目标种族触发的神圣净化都会强化本次攻击。

因此玩家支付高额公共资源后立刻获得一次完整爆发，不需要再承担“昂贵启动后空过一轮”的手感损失。

### 4. 残心流收益

10至11层宣叙提供高额暴击属性，并通常支持三次强化二技能。强化二技能是残心流的主要输出，消耗4层换取高额行动伤害；一技能则允许玩家以1层为单位延长或调整形态。

最后不足4层的宣叙可以被强化二技能一次性消耗，不会卡住技能，也不需要额外安排清层动作。

### 5. 退出成本

宣叙归零后形态自动结束，二技能恢复常态并重新具备获得残心的能力。循环可以重新从常态准备开始。

整个过程没有单独的退出技能或无伤害清算回合，因此形态结束本身不会额外浪费行动。

### 6. 对1技能叠层的准确评价

不能只看到“每次获得5层、上限11”就判断第三次技能溢出4层。应当结合完整循环评价：

- 任意两次技能便能取得10层，减少固定连段。
- 一技能0费，补层不占用技能点。
- 终结技需要等待8至12升华点，准备期本来就可能容纳额外行动。
- 10层和11层都能完成三次强化二技能。
- 11层提供额外暴击属性和十一连击风味，但不是必须完成的门槛。

这套5层获取的目的不是要求玩家为了最后1层专门行动，而是降低进入完整循环的难度和技能顺序限制。

## 八、天使队玩法

### 1. 全员天使判定

全员天使只检查三个Main。Sub不常驻显示，也不参与这项归属检查。

条件成立后，优纪获得物理防御，天使侧角色获得最终伤害和暴击伤害。优纪因此既是天使队主要输出，也是阵营光环来源。

### 2. 天使立场的早期补强

初期只有两名天使角色，单靠固有归属无法组成三个Main全员天使。优纪位于Sub时，可以通过4费护援技让当前Main在两回合内被视为天使，使其他天使角色的全员判定得以成立。

这项设计没有直接降低全员条件，而是提供临时阵营转换。未来天使角色增加后，原有条件仍可继续使用，天使立场则保留跨阵营编成价值。

### 3. 当前团队玩法边界

当前天使队主要通过归属检查和属性光环建立联系。天使队友的具体技能、行动顺序和状态变化不会反向改变优纪的残心流。

因此它目前属于“个人主C循环加阵营外壳”，还不是由成员上场、撤退、协同攻击等行为共同组成的团队作战系统。后续若参考鸿园君主，应当学习队员行为如何进入核心循环，而不是继续增加更多条件式属性BUFF。

## 九、与优纪[ALO]的区分

优纪【ALO】围绕速度差工作：对手更快时获得对等实力，自己更快时通过圣母圣咏放大领先。她的深度主要存在于配速、是否携带Sub和关卡目标速度。

优纪【天使】则放弃速度差主轴，改为：

- 残心与残心宣叙转换。
- 暴击率和暴击伤害。
- 8至12升华点超额支付。
- 残心流形态和强化二技能。
- 天使阵营归属与敌方种族对策。

两个版本没有重复使用“绝剑速度很快”作为唯一解释。普通优纪偏向自动适应和编成研究，天使优纪则偏向公共资源规划与爆发形态管理。

## 十、设计优点

### 1. 资源生命周期完整

残心具有产生、转换、提供属性、分档消费和归零退出。玩家能够从资源变化直接理解当前处于准备、启动、爆发还是收尾阶段。

### 2. 统一产量降低固定连段

常态一、二技能都获得5层，使玩家可以根据技能点和输出需要自由选择准备按钮，不会因为叠层效率差异被迫执行唯一技能顺序。

### 3. 两种消耗速度定义技能职责

一技能消耗1层并保持0费，强化二技能消耗至多4层并承担主输出。它们不追求相同资源效率，而是分别服务调整和爆发。

### 4. 不足4层时不会卡手

强化二技能可以消耗4层及以下的全部剩余层数，使最后一次主输出自然结束形态，不需要先插入额外清层技能。

### 5. 本次攻击先享受资源

宣叙在攻击结束后才扣除。玩家牺牲的是后续形态时间，不会因为使用强化技能反而降低当前攻击的暴击属性。

### 6. 终结技当场制造并兑现

超额支付、形态转换、暴击属性和种族特攻都在当前终结技内完成，不把高成本启动的回报推迟到下一次行动。

### 7. 强制超额支付形成团队时机选择

玩家不能在技能内选择支付档位，只能通过全队升华点安排决定优纪最终消费多少。这让公共资源竞争成为实际战术。

### 8. 数字11成为角色语言

资源上限与多项11%效果共同对应圣母圣咏十一连击。数字既有原作记忆点，也参与真实伤害和形态长度。

### 9. 临时归属缓解早期阵营缺员

天使立场使非天使Main能够临时进入阵营判定，在不修改全员条件的情况下解决初期只有两名天使角色的问题。

### 10. 理论非最优路线无需强行封锁

永久保留残心流在规则上可行，但完整机会成本使它不具备实战收益。设计没有为了一项无效路线继续增加限制文本。

## 十一、缺点与风险

### 1. 个人循环与阵营玩法相对平行

残心流已经形成完整个人玩法，天使队却主要停留在归属检查和属性加成。两者同时存在，但没有互相改变具体行动。

### 2. BUFF展示容易暴露代码结构

同一项天使灵装通过两个同名BUFF分别发放自身防御和队伍伤害。实现合理，但如果界面直接展示两个同名效果，玩家需要自行判断它们的来源和对象。

### 3. 单次终结技读取的效果较多

日向流、绝剑、残心宣叙、神圣净化和天使之力可能同时作用于一次攻击。若界面只展示状态图标，玩家很难预估当前终结技的实际强度。

### 4. 强制超额支付可能影响队友计划

优纪在9至12升华点时会自动增加消耗。不了解规则的玩家可能原本想保留资源给队友，却被终结技一次吞掉。必须在按钮费用和释放预览中明确显示本次实际消耗。

### 5. 种族对策依赖公共Tag可见性

神圣净化只有在玩家能提前识别恶魔、亡灵和魔物归属时才属于可规划的对策玩法。如果Tag隐藏在后台，它就会变成无法判断来源的随机增伤。

### 6. 多项乘区叠加提高强度评估难度

高层宣叙、天使队最终伤害、日向流、神圣净化和绝剑可能集中在同一终结技。不能只按单项11%或20%判断，需要用完整配队和实际暴击系统测试总收益。

### 7. 多个实验方向增加理解成本

形态资源、超额支付、暴击体系、阵营队、临时阵营转换和种族特攻都集中在同一角色。每项机制都有用途，但玩家初次阅读时不容易立即判断哪些是主轴、哪些只是阵营附加效果。

## 十二、设计意图分析

### 1. 基本可以确定

- 用残心和残心宣叙测试准备资源向形态资源的转换。
- 用一层与四层消费测试同一形态中的调整技能和主输出技能。
- 用8至12点强制消费测试公共升华点的超额支付。
- 让终结技在同一次攻击中完成形态转换和收益兑现。
- 用11层与11%系列数值保留圣母圣咏十一连击记忆点。
- 用天使立场解决早期天使角色数量不足的问题。
- 用Main归属而非Sub常驻判定适配当前战场显示逻辑。

### 2. 较可能的意图

- 将优纪塑造成天使队最高档位主C，而不是阵营辅助。
- 让强化二技能成为残心流的主要伤害来源，一技能负责0费调整。
- 允许玩家根据团队资源选择8点快速启动或12点完整爆发。
- 通过恶魔、亡灵和魔物特攻建立天使阵营的对立目标。
- 在一个偏原创版本中同时验证形态、阵营和暴击三个设计方向。

## 十三、值得学习的设计方法

### 1. 先设计完整循环，再评价单个数字

叠层数量、上限和消耗不能脱离准备行动、技能费用、终结技需求和形态收益单独评价。应当检查整轮循环的总成本、总输出、启动速度和退出手感。

### 2. 资源应当拥有明确生命周期

产生、转换、利用和退出缺一不可。形态资源如果只能叠加和增伤，就很容易退化成普通BUFF。

### 3. 少量溢出可以换取自由顺序

技能统一获得5层，让任意两次行动都能达到10层。无需为了精确填满11而给不同技能设置容易固化连段的产量。

### 4. 用消费速度区分技能，而不是强求平级

一技能负责延长和调整，二技能负责高额行动输出。角色可以拥有明确主输出，不必让所有按钮在任何场景都同样有效。（比如对面的前排只剩一丝血了，可以用一技能收掉，然后再用强化二技能去打下一位角色）

### 5. 资源不足时优先保证技能可用

强化二技能消耗4层及以下，避免剩余1至3层时卡手。资源规则应制造取舍，而不是阻止玩家操作。

### 6. 高成本形态启动应当立即回报

终结技当场获得并使用所有强化，避免玩家支付大量公共资源后还要等待下一次行动。

### 7. 强制消费可以把选择转移到行动时机

不提供档位菜单，而是让玩家提前安排全队升华点。前提是实际消费量必须清楚可见。

### 8. 临时阵营转换可以作为阵容桥梁

在阵营角色不足时，不必永久降低组队条件。临时Tag能维持未来扩展空间，并为Sub提供独立价值。

### 9. 评价路线必须计算完整机会成本

规则允许不等于实战有效。理论永久形态如果要求主C跳过更高收益的行动，就不能只凭“可以无限保持”判断为漏洞。

### 10. 数字主题必须同时服务玩法

11在本角色中既对应原作记忆，也提供可用的资源上限和暴击属性。主题数字只有进入真实循环时才有价值。

## 十四、不宜直接照搬的部分

### 1. 不要把残心转换做成形态角色通用模板

准备资源转换成持续资源适合这次剑技宣叙，但其他角色需要根据自身行为重新确定资源的产生和退出方式。

### 2. 不要普遍使用强制超额支付

自动吞掉全队公共资源必须有足够高的即时收益和清晰预告。普通终结技不应只为增加选择感就擅自提高费用。

### 3. 不要把条件式属性光环当作完整团队作战

全员归属与阵营增伤只能建立队伍入口。真正的团队玩法还需要成员行动、技能或状态彼此改变。

### 4. 不要把代码BUFF拆分直接写进技能认识

实现层可以拆分效果，设计文本应按来源、对象和玩家认识重新组织。

### 5. 不要让玩家手动相加大量一回合BUFF

当多个效果共同强化当前攻击时，界面应直接提供预计费用、预计暴击和预计伤害修正。

### 6. 不要使用不可见的种族对策

敌方Tag必须在战斗前或详情页清楚显示，否则对策增伤无法进入玩家计划。

### 7. 不要为了象征数字破坏完整循环

主题数字可以影响上限和倍率，但仍需检查是否容易进入循环、是否产生卡手以及成本是否能获得相应收益。

### 8. 不要看到理论永久状态就立即增加限制

先比较该路线与正常输出的行动效率、资源效率和机会成本。只有它形成实际最优解时，才需要修改规则。

### 9. 不要在未分主次时堆叠多个实验方向

一个角色可以测试多项机制，但成文与界面必须明确核心、入口、阵营外壳和附带对策的层级。

## 十五、信息反馈要求

为了让复杂度服务研究而不是查表，战斗界面应明确展示：

- 当前残心和残心宣叙层数。
- 当前宣叙提供的暴击率与暴击伤害。
- 当前是否处于残心流。
- 二技能当前形态和释放后预计剩余宣叙。
- 常态终结技本次实际消耗8至12中的多少升华点。
- 本次预计获得的日向流与绝剑。
- 当前目标是否触发神圣净化。
- 三个Main是否满足全员天使。
- 天使立场的剩余回合和实际覆盖对象。
- 本次终结技最终读取到的全部强化来源。

## 十六、总结

优纪【天使】的核心不是单纯叠满11层，也不是12费大招，而是完成一轮顺畅的资源生命周期：常态技能快速准备残心，终结技消费公共升华点并立即转换形态，残心流用强化二技能集中输出，再以不产生卡手的方式耗尽宣叙并回到常态。

这套循环中，5层获取的价值在于降低启动难度和固定顺序，1层与4层消耗负责区分调整与主攻，8至12点终结技则把团队资源规划变成形态强度。单个数字是否溢出，必须放回整轮行动成本和收益中评价。

天使阵营目前仍是相对独立的编成外壳。天使立场很好地解决了初期人数不足，但全员判定与属性光环尚未让队友行为真正进入残心流。后续若继续发展天使队，最值得参考的是鸿园君主式的成员协作，而不是继续叠加更多阵营BUFF。

这次设计最值得保留的是完整资源循环、不同消费速度和当场兑现的终结技；最需要控制的是多项BUFF的展示、强制超额支付的信息透明度，以及个人主轴与阵营玩法之间的分离感。
