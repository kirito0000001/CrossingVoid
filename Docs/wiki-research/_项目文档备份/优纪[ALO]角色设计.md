# 优纪[ALO]角色设计

> 本文集中记录优纪【ALO】的技能资料、速度差结算、编成玩法、设计评价与可复用经验。截图中容易产生歧义的持续时间、速度差转换和终结技结算顺序，以设计者后续确认的规则为准。

## 一、角色设计概览

### 1. 基础定位

- 速度值：800
- 物理抗性
- 双属性C
- 中排攻击
- 高速压制
- 闪避守备

优纪的基础速度高于亚丝娜【SAO】的758，用数值直接表现“绝剑”在虚拟世界中的速度优势。

### 2. 核心角色认识

优纪已经能够依靠本能完成大部分战斗。她平时喜欢与其他玩家单挑，也未必从一开始就拿出全部实力；遇到真正值得认真对待的对手时，才会通过圣母圣咏展现绝剑的上限。

因此，这个角色不追求大量回合内操作。她的主要选择发生在：

- 是否携带Sub。
- 如何控制组合速度。
- 选择什么速度的敌人作为目标。
- 什么时候使用圣母圣咏，从随意应战转向认真爆发。

普通玩家可以直接使用，速度关系会自动转化为收益；愿意研究的玩家则可以通过编成与关卡速度挖掘更高上限。

## 二、被动：单挑五五开

当敌方当前只剩一名角色时，优纪在自身行动开始时获得1层 **专注决斗**。

专注决斗是动态条件状态：

- 敌方只剩一人时存在。
- 敌方人数恢复到两人及以上时移除。
- 它不会因为图片标注“持续时间无限”就在出现增援后永久保留。

这项被动只承担单挑风味，不是整套玩法的核心。3%最终伤害用于让真正的一对一场面略有强化，不负责改变完整战斗循环。

## 三、技能资料

### 1. 一技能：极速连斩

| 项目 | 内容 |
| --- | --- |
| 费用 | 0技能点 |
| 目标 | 中排攻击 |
| 守备 | 闪避（2） |
| 物理倍率 | 30% / 60% / 120% / 200% / 230% |
| 异能倍率 | 20% / 30% / 60% / 100% / 130% |
| 特殊效果 | 技能成功释放时，获得1点技能点 |

极速连斩本身0费，成功后额外获得1点技能点，因此是稳定的技能点生产手段。它保证优纪在没有形成理想速度差时仍然拥有基础队伍价值，但不取代速度控制的爆发上限。

### 2. 二技能：绝剑光舞

| 项目 | 内容 |
| --- | --- |
| 费用 | 3技能点 |
| 目标与标签 | 自身加攻 |
| 守备 | 闪避（3） |
| 物理倍率 | 80% / 130% / 200% / 300% / 480% |
| 异能倍率 | 30% / 50% / 100% / 130% / 160% |
| 特殊效果 | 技能成功释放时，若攻击目标速度高于自身，则获得等同于双方速度差的拿出对等实力 |

速度差按1比1转换为层数。例如目标比优纪快100点，就获得100层拿出对等实力。该状态最多200层，因此最高提供40%物理伤害提升。

这个技能表现优纪面对更快的对手时不会被速度压制，而是自动拿出足以与其对等的实力。

### 3. 护援技：贯穿之剑

| 项目 | 内容 |
| --- | --- |
| 费用 | 2技能点 |
| 目标 | 后排攻击 |
| 守备 | 闪避（3） |
| 物理倍率 | 10% / 30% / 70% / 130% / 180% |
| 异能倍率 | 20% / 20% / 30% / 50% / 60% |
| 特殊效果 | 无 |

贯穿之剑只在优纪位于Sub位置时使用，不需要接入本体的速度差机制。它是简单、独立的后排攻击护援技。

### 4. 终结技：圣母圣咏

| 项目 | 内容 |
| --- | --- |
| 费用 | 10升华点 |
| 目标 | 中排终结 |
| 守备 | 闪避（5） |
| 物理倍率 | 40% / 100% / 300% / 400% / 450% |
| 异能倍率 | 110% / 250% / 440% / 600% / 690% |
| 特殊效果 | 成功释放时，将自身速度永久提高到全场当前最高速度加100，累计最多提高600；随后根据与攻击目标的速度差获得虚拟世界本地人 |

圣母圣咏的结算顺序是：

1. 读取全场当前最高速度。
2. 将优纪速度提高到该速度加100。
3. 永久保留本次速度提升，累计提升不超过600。
4. 比较提速后的优纪与攻击目标。
5. 若优纪更快，按1比1将速度差转换为虚拟世界本地人。
6. 虚拟世界本地人立即强化本次圣母圣咏的物理伤害部分。

因此，大招在同一次技能中完成认真起来、超越全场、读取领先差距和立即爆发，不需要等待下一次行动兑现。

## 四、特殊效果

| 效果 | 最大值 | 持续时间 | 作用 |
| --- | ---: | ---: | --- |
| 拿出对等实力 | 200 | 2 | 每层使自身物理伤害提高0.2%，最高提高40% |
| 虚拟世界本地人 | 无上限 | 1 | 每层使自身物理伤害提高0.5%，立即作用于本次圣母圣咏 |
| 专注决斗 | 1 | 动态存在 | 敌方仅剩一人时提高3%最终伤害，敌方人数增加后移除 |

### 1. 拿出对等实力

这项状态读取“目标比优纪快多少”。它不是让优纪单纯追求最高速度，而是允许她在较慢时把劣势转换成物理伤害补偿。

### 2. 虚拟世界本地人

优纪因长期完全潜行，对虚拟世界的身体与速度拥有接近本能的适应。圣母圣咏让她成为全场最快，再把领先目标的速度差转换为本次物理伤害。

它没有层数上限，因此对极低速度目标可能产生极端收益。正常关卡、单独上场和特殊低速敌人的强度必须分别评价。

### 3. 专注决斗

专注决斗只表达优纪进入一对一时的战斗气氛。它的价值较小是有意的风味权重，不需要为了增加存在感再扩展成一套独立决斗资源。

## 五、两种速度关系

### 1. 随意应战：对手更快

当攻击目标比优纪快时，绝剑光舞根据差距获得拿出对等实力。对手越快，优纪越会拿出足以维持对等交锋的物理伤害。

这个方向对应她平时与他人单挑、未必从一开始就展现全部实力的状态。

### 2. 认真对待：优纪更快

圣母圣咏永久提高优纪速度，使她超过全场当前最快角色，并立即把与攻击目标的领先差距转换为虚拟世界本地人。

这个方向对应她开始认真，以绝剑真正实力结束战斗。

### 3. 当前衔接问题

两套逻辑在概念上互补：对手更快时获得补偿，优纪更快时放大优势。但当前技能没有把它们明确组织成“随意应战 → 认真对待”的状态转变。

永久加速还会逐步降低拿出对等实力的触发机会。若这是认真以后不再需要迁就对手的有意结果，就需要通过状态名称、演出或界面反馈明确告诉玩家；否则玩家只会感到二技能的一部分效果随着大招使用而逐渐消失。

这正是本角色手感割裂的主要来源，而不是角色回合内选择太少。

## 六、Main/Sub与单独上场

### 1. 携带Sub

携带Sub会提高角色组合的白值、速度，并补充护援技、连携和其他守备。更高速度会缩小目标领先优纪的差距，使拿出对等实力较难获得大量层数，但整个组合更加稳定完整。

### 2. 单独上场

优纪不携带Sub时只有自身800速度，在面对完整角色组合时反而更容易成为全场较慢的一方，从而通过绝剑光舞获得较大的速度差补偿。

代价包括：

- 损失Sub提供的上千白值攻击力。
- 失去Sub护援技与连携能力。
- 失去通过Sub补充防御或反击守备的机会。
- 整体基础输出与生存能力下降。

因此，单走不是无代价获取巨额增伤，而是以角色组合完整性换取速度差倍率的高风险编成路线。

设计者估算，在正常完整组合与常规敌人速度区间中，速度差增伤通常处于可控范围；单走与特殊配速可能把增伤进一步放大，极端配置下可达到约960%物理增伤，但同时需要承担大量白值与功能损失。

### 3. 特殊低速敌人

当敌人速度只有个位数或十位数时，圣母圣咏可能读取到异常巨大的领先差距，出现一次大招直接击杀的结果。

这是速度差公式与特殊敌人数值共同产生的极端对局，不代表普通关卡中的常态强度。

## 七、实际玩法

### 1. 普通使用

不研究速度配置的玩家可以直接使用优纪：

- 极速连斩提供0费攻击与1点技能点。
- 目标更快时，绝剑光舞自动给予物理增伤补偿。
- 圣母圣咏自动让优纪超过全场最高速度，并立即提高本次物理伤害。
- 敌方只剩一人时，专注决斗动态生效。

角色可以依靠本能自动完成速度判断，玩家不必每回合手算层数。

### 2. 深入研究

熟悉角色的玩家可以进一步规划：

- 是否携带Sub。
- 使用什么速度的Sub。
- 让优纪在大招前保持较慢，还是更早进入永久高速。
- 选择当前速度差更有利的目标。
- 针对特殊低速敌人使用圣母圣咏。

优纪的深度主要存在于编成和关卡理解，而不是增加更多回合按钮。

### 3. 信息反馈要求

为了让研究深度不退化成查表负担，战斗界面最好能够明确展示：

- 当前双方速度差。
- 本次转换的状态层数。
- 当前物理伤害提升比例。
- 圣母圣咏已经永久提高的速度总量。
- 专注决斗当前为何生效或失效。

## 八、闪避专精与Sub守备

优纪的所有技能均使用闪避守备，符合高速剑士的专精。她不需要在Main技能组内同时覆盖防御与反击。

玩家可以通过Sub决定角色组合的守备范围：

- 继续搭配闪避Sub，强化高速回避。
- 搭配防御Sub，应对多段攻击与闪避次数不足。
- 搭配反击Sub，补充拼刀和还击能力。
- 选择单走，放弃Sub守备以换取更大的速度差空间。

因此，全闪避不是缺点，而是与Sub编成和单走选择共同构成的角色专精。

## 九、设计优点

### 1. 低操作门槛符合角色本能

优纪不需要玩家替她进行大量战术计算。速度差由系统自动读取，普通玩家可以直接体验绝剑的强大，这与她依靠本能完成虚拟战斗的状态一致。

### 2. 编成选择真正改变机制

Sub并非只增加属性。是否携带Sub会改变速度差方向、增伤空间、白值、守备和技能，形成稳定完整与高风险倍率之间的选择。

### 3. 同时服务普通玩家与研究型玩家

角色拥有可直接使用的稳定下限，也允许爱好者通过配速、单走和敌人速度挖掘特殊上限。这种玩家分层对完整角色池很有价值。

### 4. 相反速度条件共同解释绝剑

对方更快时，优纪拿出对等实力；优纪更快时，她以虚拟世界本地人的优势扩大领先。无论面对怎样的速度关系，她都拥有符合人设的回应。

### 5. 圣母圣咏结算完整

大招在同一次技能内制造速度优势、读取差距并立即兑现伤害，不会把爆发拆到下一次行动。

### 6. 永久加速表现逐渐认真

优纪每次释放代表剑技都会永久提高速度，逐步进入更高实力层级。不可逆成长比短暂速度BUFF更能表现她从玩闹转向认真。

### 7. 双属性承担原作与平衡双重作用

ALO剑技具有更明显的魔法异能表现，圣母圣咏以异能倍率为主符合版本环境。与此同时，异能倍率不会被两套物理速度差增伤完全放大，避免大招上限失控。

### 8. 数值直接表达角色关系

800基础速度高于亚丝娜【SAO】的758，不需要额外被动就能表现绝剑在速度层面的优势。

### 9. 小型效果保持正确权重

专注决斗只提供少量最终伤害，作为一对一风味存在，没有抢占速度差主玩法，也没有额外制造决斗资源。

## 十、缺点与风险

### 1. 两套速度方向缺少明确衔接

拿出对等实力与虚拟世界本地人分别处理较慢和较快，但技能没有正式建立两者之间的阶段关系。这使概念上的“随意应战与认真对待”在操作上显得割裂。

### 2. 永久加速会逐步关闭较慢路线

优纪越快，绝剑光舞越难触发拿出对等实力。若界面没有明确说明已经进入认真阶段，玩家可能把它理解成技能功能无故减少。

### 3. 速度差公式不够直观

一比一层数转换、两种不同单层倍率、最大200与无上限、Sub速度与永久加速共同参与，最终收益难以凭技能文本直接预估。

角色可以保留研究深度，但必须提供本次层数和实际增伤反馈。

### 4. 常态与极端对局跨度较大

普通完整组合中的收益可能较为克制，单走或面对极低速度敌人时却可能出现数倍增伤甚至直接击杀。统一调整基础倍率很难同时照顾所有速度区间。

### 5. 单走路线容易成为隐藏答案

如果界面只提示失去Sub后战力下降，却不展示速度差可能带来的补偿，大部分玩家不会把单走理解成有意设计的编成方案。

### 6. 动态状态文本容易误导

专注决斗标注持续时间无限，却会随敌方人数变化而移除。动态条件必须明确写入说明，不能只依靠持续时间字段表达。

### 7. 基础稳定性与角色主轴可能发生观感竞争

极速连斩稳定产出技能点，在速度差收益未被玩家看见时，可能成为最容易感知的价值。解决方式不是削掉产点，而是让速度差的层数与伤害反馈足够清楚。

## 十一、设计意图分析

根据技能结构和设计者补充，可以基本确认：

- 优纪的低操作门槛用于表现依靠本能战斗，而不是因为玩法尚未设计。
- 角色真正的决策重点在Main/Sub编成、速度控制和是否进入认真状态。
- 拿出对等实力表现面对更快对手时维持对等交锋。
- 虚拟世界本地人表现优纪长期完全潜行形成的虚拟身体优势。
- 圣母圣咏负责让优纪成为全场最快，并立即兑现领先速度差。
- 永久加速表现优纪在战斗中逐步拿出真正实力。
- 圣母圣咏偏异能既符合ALO剑技，也用于限制物理速度差增伤上限。
- 专注决斗只承担单挑风味，不是主要循环。
- 极速连斩产点保证角色在普通速度环境中仍有稳定价值。
- 全闪避建立高速专精，其他守备由Sub补足。

当前未能完全实现的意图是：

- 随意应战与认真对待没有形成清楚可感知的两个阶段。
- 永久加速关闭较慢分支时，缺少明确的状态转变反馈。

## 十二、值得学习的设计方法

### 1. 操作复杂度也可以还原角色

依靠本能作战的角色可以低操作、自动判断。不要为了证明玩法存在而强行增加资源和按钮。

### 2. 把深度放在编成与关卡理解中

玩法不只发生在回合内。Main/Sub、单独上场、速度和敌人属性都可以成为玩家主动控制的条件。

### 3. 同时设计易用下限与研究上限

普通玩家可以直接使用，角色爱好者又能通过理解系统显著提高表现，是值得保留的角色池层次。

### 4. 让数值差成为可以操纵的资源

速度不只是先后手属性，也可以通过编成和技能主动改变，再转换成战斗收益。

### 5. 用相反条件表现角色面对不同对手的态度

面对更强者补足实力、占据优势时发挥本领，是很好的角色逻辑。使用时必须继续明确两种条件是并行对策还是阶段变化。

### 6. 在同一技能内完成制造与兑现

圣母圣咏先制造速度领先，再立即读取并强化本次技能，避免大招奖励延迟到下一行动。

### 7. 用完整机会成本平衡极端配装

允许玩家放弃Sub白值、守备和技能换取特殊倍率，比直接禁止极端配置更有研究价值。评价时必须同时计算得到与失去的部分。

### 8. 用伤害构成限制单一增伤上限

专属增伤只作用于部分伤害，而代表技能保留另一属性倍率，可以在不删除角色特色的情况下控制爆发。

## 十三、不宜直接照搬的部分

### 1. 不要把速度差换伤害作为高速角色模板

这套机制依赖绝剑、单挑习惯与虚拟世界适应。其他高速角色可能更适合先手、连击、支援或反应玩法。

### 2. 不要让相反条件停留在互不相干的技能条目

相反条件需要明确成为并行选择、前后阶段或对不同敌人的策略。否则角色逻辑正确，实际操作仍然割裂。

### 3. 不要依靠永久变化悄悄关闭旧机制

若永久成长意味着进入新阶段，应提供明确状态、演出和文本反馈，让玩家知道功能变化是设计结果而不是失效。

### 4. 不要用复杂公式代替反馈

公式可以为研究型玩家提供深度，但层数、差值和最终收益必须在战斗中可见。

### 5. 不要只按理论最高倍率判断强度

极端增伤可能同时失去大量白值、Sub技能、守备和连携。强度评价必须包含完整编成成本与普通对局表现。

### 6. 不要把素材化的小型风味强行扩写成主循环

单挑风味只需保持正确权重。为每个角色特点分别创建资源，会破坏速度差主轴。

### 7. 不要用新增资源修复现有机制割裂

当前问题是两套速度方向缺乏关系，而不是机制数量不足。继续添加认真值或决斗值只会增加理解负担。

## 十四、待补充边界

- 拿出对等实力与虚拟世界本地人的持续时间在具体回合节点如何减少。
- 永久速度提升在界面中的显示方式，以及达到600上限时的反馈。
- 两种速度差物理增伤能否在同一次圣母圣咏中同时存在并叠加。
- 特殊低速敌人是否需要速度差收益上限或关卡修正。

这些内容在确认前不写成既定规则。

## 十五、总结

优纪最值得保留的设计核心是：

> 平时依靠本能与对手维持对等交锋，真正认真时通过圣母圣咏永久超越全场，并将速度关系立即转换成绝剑的爆发。

她的主要选择不在每回合拥有多少按钮，而在Main/Sub编成、是否单走、速度控制、目标条件和进入认真状态的时机。普通玩家能够直接使用，研究型玩家则可以通过速度差找到特殊解法。

当前最主要的问题不是角色太简单，而是拿出对等实力与虚拟世界本地人没有被明确组织成“随意应战到认真对待”的连续状态。其他需要关注的风险包括公式反馈不足、永久加速关闭较慢分支，以及普通对局与特殊低速敌人之间过大的强度跨度。
