# 御坂美琴角色设计

> 本文记录御坂美琴当前已经收束的角色方向、拼刀与标记机制、技能效果、实际玩法和设计风险。当前仍处于机制设计阶段，尚未确定的技能数值、守备类型和结算边界不写成既定规则。

## 一、角色设计概览

### 1. 选取时期

本角色选取妹妹篇以前、御坂美琴刚刚认识上条当麻时的状态。

这一时期的御坂美琴拥有以下特点：

- 凭借真实成绩从Level 1成长为Level 5，对自己的实力有强烈自信。
- 好胜、急躁，遇到不服气的结果会立刻再次挑战。
- 战斗方式直接，具有近似街头斗殴的气质，不习惯长期准备后再出手。
- 相信自己的力量足以解决绝大多数问题，习惯亲自处理眼前的麻烦。
- 无法接受自己的能力被轻易否定。攻击被挡住或正面对抗失败，反而会促使她继续打下去。

### 2. 基础表现限制

现有素材已经确定三个主动技能的主要表现：

- 一技能：攻击敌方前排单体，并附带少量群体伤害表现。
- 二技能：对敌方群体进行大范围放电。
- 终结技：发射超电磁炮。

技能费用、附加效果、目标细则和守备关系仍可根据完整玩法调整。

### 3. 核心设计边界

御坂美琴不适合双形态，也不采用长期暖场、逐层启动或积攒专属资源后才完整发挥的结构。

她释放技能时应当立即得到完整效果。角色深度来自拼刀结果、敌方守备、敌人的攻击目标、我方丢弃选择和行动时机，而不是等待数回合完成启动。

## 二、核心体验

御坂美琴主动进入反击守备，迫使攻击自己的敌人正面拼刀。拼刀成功时，她立即以更强的伤害和击飞压倒对手；拼刀失败时，她承受的损失会被压低，同时记住这个让自己吃瘪的敌人，并在接下来的攻击中讨回来。

整套玩法不是要求玩家固定追求拼刀胜利或失败，而是让两种结果分别通往不同收益：

- **拼刀成功**：获得更高的拼刀伤害和更远的击飞距离，当场赢下正面对抗。
- **拼刀失败**：敌人获得短暂标记，御坂随后通过异能增伤和技能点削减进行回敬。
- **攻击完全无效**：即使没有发生拼刀，只要御坂的攻击没有造成伤害，她同样会记住否定自己力量的目标。

角色要求玩家扮演的行为是：

> 主动把战斗变成正面对抗；赢了就把敌人轰飞，输了也不会退让，而是立刻找回场子。

## 三、拼刀机制基础

拼刀守备值根据角色生命值百分比生成，并按照被攻击者的基础抗性决定本次拼刀采用的伤害属性。

玩家可以通过两种方式影响御坂的拼刀结果：

- 在养成中减少生命值投入，使御坂生成的拼刀守备值较低，更容易进入拼刀失败分支。
- 主动与物理抗性目标拼刀，使本次拼刀更容易按照不利于御坂的属性关系结算。

这不是要求御坂必须故意拼输。生命值较高的配置可以稳定争取拼刀成功，生命值较低或针对特定抗性的配置则更容易使用失败后的标记路线。两条路线能否同时成立，取决于即时胜利收益与后续回敬收益是否接近。

## 四、拼刀专精

御坂美琴拥有以下拼刀修正：

- 御坂因拼刀受到的伤害降低52%。
- 御坂造成的拼刀伤害提高52%。
- 御坂拼刀成功后的击飞距离变为原来的2倍。

这组效果让她在正面对抗中无论胜负都能继续战斗：胜利时表现为强势压倒，失败时则降低进入标记路线的即时损失。

## 五、强制反击守备

当御坂美琴处于反击守备状态时，如果敌方使用单体攻击御坂，则敌方当前的守备状态会被替换为反击守备。

由于攻击方与被攻击方同时处于反击守备，双方会进入拼刀。这个效果使御坂不必被动等待敌人刚好使用反击，而是能够把防御或闪避对手拖入正面对抗。

群体攻击不会通过这项效果被强制转为拼刀。玩家需要根据敌方技能的单体目标、行动顺序和御坂站位，决定何时让她保持反击守备。

## 六、标记

### 1. 施加条件

满足任一条件时，给对应敌人施加标记：

- 御坂美琴与对方拼刀失败。
- 御坂美琴的攻击没有对目标造成伤害。

同一次结算同时满足两个条件时也只需要保留一个标记，标记不依靠重复叠层提高效果。

### 2. 持续时间

标记持续1回合。

较短的持续时间用于表现御坂受到挫折后立即回敬，而不是长期储存标记、等待固定爆发。玩家如果希望触发全体标记条件，就必须在当前战局中迅速完成，不能把进度跨越多个回合慢慢保存。

### 3. 攻击标记目标

御坂美琴攻击带有标记的目标时：

- 扣除敌方1点技能点。
- 御坂对该目标造成的异能伤害提高10%。

技能点削减每个技能最多触发一次。无论该技能拥有多少段攻击、命中多少个标记目标或产生多少次溅射，整次技能都只会扣除敌方1点技能点。

标记即使没有凑齐全体，也能立即提供异能增伤和技能点压制，因此不会因为磁控溅射未能出现而完全失去价值。

## 七、丢弃落雷

我方角色行动时丢弃技能，御坂美琴会对随机敌人追加一次落雷。

这项效果把队伍的守备选择转化为御坂的额外进攻：其他角色为了生成更高守备值而放弃原技能效果时，御坂会主动补上一次攻击。

落雷采用随机目标，因此它能够带来临场变化，但玩家无法稳定指定它攻击某个标记目标。落雷的伤害规模需要结合全队一回合内可以丢弃的次数进行测试，避免防守行动同时获得过高的免费输出。

## 八、磁控溅射

当触发落雷时，如果敌方当前存活人数为3人，并且三名敌人全部带有标记，本次落雷升级为 **磁控溅射**：

- 改为超大范围落雷。
- 造成更高伤害。
- 使敌方全体麻痹1回合。
- 清除敌方全体身上的标记。

磁控溅射表现三名敌人同时处于放电环境后，电流在目标之间扩散并形成全场麻痹。只有三名当前存活敌人同时带有标记时才获得麻痹效果；单体Boss和双目标战斗仍可正常触发普通落雷和标记收益，但不会仅因“当前全体均被标记”而反复麻痹。

磁控溅射不属于双形态，也不替换御坂的技能组。它只是战局满足特殊条件时出现的一次即时清算。

## 九、技能资料

### 1. 一技能

| 项目   | 当前设计           |
| ---- | -------------- |
| 费用   | 0技能点           |
| 目标   | 前排单体，并附带少量群体伤害 |
| 特殊效果 | 攻击结束时，破除敌方前排护盾 |

一技能先完成原本的攻击，再破除前排护盾。因此本次攻击仍可能被护盾挡住；如果完全没有造成伤害，还会给目标施加标记。技能结束后，前排防护被清除，为后续攻击制造直接突破口。

### 2. 二技能

| 项目   | 当前设计                     |
| ---- | ------------------------ |
| 费用   | 3技能点                     |
| 目标   | 敌方群体                     |
| 特殊效果 | 造成伤害时使目标速度降低30，累计最多降低200 |

二技能以大范围放电直接干扰敌方行动速度。速度削减从每次有效伤害中立即产生，不需要先建立长期资源。

群体攻击也可以同时检查多个目标是否受到伤害。被护盾、闪避或其他效果完全阻止伤害的目标会获得标记，正常受到伤害的目标则承受速度降低。

### 3. 终结技：超电磁炮

| 项目   | 当前设计           |
| ---- | -------------- |
| 费用   | 10升华点          |
| 表现   | 超电磁炮           |
| 特殊效果 | 攻击开始时，破除敌方群体护盾 |

超电磁炮在造成伤害以前先完成群体破盾，使本次终结技能够直接伤害原本受到护盾保护的目标。

它与一技能形成明确层级：一技能在攻击结束后拆除前排防护，服务后续行动；超电磁炮则在攻击开始时先破盾，再立即兑现本次爆发。

## 十、实际玩法

### 1. 常规行动

御坂不需要预热即可使用完整技能：

- 一技能以0费攻击前排，并在结算后拆除前排护盾。
- 二技能立即造成群体伤害并降低敌方速度。
- 超电磁炮在攻击前群体破盾，直接完成爆发。

即使没有发生拼刀、没有敌人被标记、队友也没有丢弃技能，御坂仍然拥有完整的常规输出和破盾能力。

### 2. 主动制造拼刀

玩家让御坂进入反击守备并站到敌方单体攻击能够命中的位置。敌人的守备会被替换为反击，从而进入拼刀。

- 拼刀成功时，御坂以提高后的拼刀伤害和双倍击飞距离立即压制对手。
- 拼刀失败时，御坂降低所受拼刀伤害，并给敌人施加1回合标记。

玩家可以通过生命值养成和敌方基础抗性倾向其中一条路线，但不应存在唯一正确的固定结果。

### 3. 立即回敬

敌人被标记以后，御坂需要在较短窗口内再次攻击：

- 对标记目标获得10%异能伤害提升。
- 每个技能最多扣除敌方1点技能点。
- 如果三名敌人全部带有标记，可以通过我方丢弃技能触发磁控溅射。

标记只有1回合，因此玩家必须决定是立即回敬当前目标，还是尝试在窗口内让三名敌人全部进入标记状态。

### 4. 队友转入守备

队友丢弃技能时，原技能效果不会发生，但会生成更高守备值。御坂通过随机落雷补充一次攻击，使队伍的防守回合仍保持进攻节奏。

如果三名敌人已经全部被标记，这次丢弃就会成为磁控溅射的触发开关。玩家不是积攒一条专属资源，而是在观察当前敌我状态后决定是否牺牲一个技能，立即兑现全场放电。

## 十一、设计优点

### 1. 拼刀胜负都符合人物

成功时强势轰飞，失败时记住对手并马上讨回来。两种结果不是普通的成功与失败，而是御坂面对正面较量的两种反应。

### 2. 失败收益不是无条件补偿

标记只持续1回合，后续仍需要御坂再次攻击才能获得增伤和技能点削减。玩家得到的是一次回敬机会，而不是拼刀失败后自动领取全部收益。

### 3. 使用本作已有系统形成个性

玩法主要读取反击守备、拼刀、抗性、生命值、护盾、速度、技能点、丢弃和行动顺序，没有增加独立资源条或双形态界面。

### 4. 敌方行为真正改变御坂的玩法

敌人是否使用单体攻击、采用什么守备、基础抗性如何、是否完全挡住御坂伤害，都会改变御坂接下来获得的结果。玩家不会对所有关卡机械执行同一套启动顺序。

### 5. 队友的防守选择也能参与循环

丢弃落雷让队友放弃主动技能时产生御坂特有的回应，同时没有要求护援技或其他角色直接携带御坂的专属资源。

### 6. 破盾效果形成技能层级

一技能在攻击后破盾，终结技在攻击前破盾。同一个效果通过不同结算时机承担准备与兑现两种作用。

### 7. 磁控溅射是稀有场面而非必经启动

只有三名敌人同时带有短期标记才会出现强化落雷。普通战斗不需要以它为前提，触发时则能形成足够鲜明的高潮。

## 十二、缺点与风险

### 1. 两条拼刀路线必须保持接近

如果标记、技能点削减和异能增伤明显强于拼刀成功收益，玩家会故意减少生命值养成；如果拼刀成功的伤害和击飞明显更强，失败路线又会退化为安慰奖。

需要比较完整周期，而不是只比较一次拼刀：

- 成功路线获得的即时拼刀伤害和击飞收益。
- 失败路线降低的受伤、后续回敬伤害、技能点削减以及标记过期风险。

### 2. 减少生命值养成可能形成反直觉答案

通过少加生命值提高拼刀失败率具有研究价值，但如果成为最优玩法，玩家会因为正常养成角色反而失去核心收益。理想状态应当是生命值投入改变路线倾向，而不是简单削弱角色。

### 3. 一回合标记的全体条件较难完成

三名敌人必须在短时间内全部拼刀获胜或完全挡住御坂攻击，随后我方还要丢弃技能触发落雷。这个条件可能在多数战斗中很少出现。

稀有本身不是问题，因为磁控溅射不是基础强度的一部分；但需要实测它是否仍有机会被玩家主动制造，而不只是技能文本中的理论效果。

### 4. 随机落雷降低目标控制

普通落雷可能命中不重要的敌人，也可能无法帮助玩家处理当前标记目标。随机性可以制造放电失控感，但落雷的触发频率和基础收益不能高到让胜负过度依赖随机目标。

### 5. 丢弃队伍可能获得过高行动经济

如果多个队友频繁丢弃技能，御坂会在队伍获得高守备值的同时连续补充攻击。必须把队友放弃的原技能价值、获得的守备收益和落雷总伤害放在一起评价。

### 6. 技能点削减可能形成资源封锁

当前已经限制为每个技能最多扣除1点，不会因多段攻击一次清空敌方技能点。仍需测试御坂的行动频率和标记覆盖率，确认连续攻击是否会长期压制敌方技能选择。

### 7. 群体先破盾需要控制强度

超电磁炮在攻击前群体破盾，可以同时消除防护并完整结算爆发。如果护盾是敌人的主要生存手段，这项效果会显著压缩防御型敌人的价值。

## 十三、值得学习的设计方法

### 1. 先决定角色如何面对胜负

拼刀只是公共系统，御坂的个性来自她怎样处理拼刀结果：胜利就把人轰飞，失败便马上记住并回敬。

### 2. 让敌人的防御成为角色输入

攻击没有造成伤害不只是一次空转，也会改变御坂接下来的目标关系。角色因此读取敌人，而不是让敌人单纯承受固定循环。

### 3. 用结算时机区分相似效果

攻击后破盾与攻击前破盾使用同一个概念，却分别服务准备和爆发。设计差异不一定需要新增状态，也可以来自效果发生的时间。

### 4. 给成功与失败设计不同价值

失败路线可以存在，但不能简单把失败转换成比成功更多的收益。两条路线应当分别提供即时压制与延迟回敬，让玩家根据配置和敌人选择。

### 5. 稀有强化不等于暖场阶段

磁控溅射来自战局临时满足的条件，不替换技能组，也不要求每场战斗必须追求。只要基础角色不依赖它，稀有高潮就不会自动变成启动流程。

### 6. 用公共守备承载自动防御

御坂的电磁防御没有另建一套独立护盾，而是通过反击守备、拼刀和守备替换进入现有战斗系统。人物能力因此成为玩家能够操作的规则。

## 十四、不宜直接照搬的部分

### 1. 不要把拼刀失败标记做成通用模板

这项机制来自御坂无法接受力量被正面否定的性格。其他角色如果没有相同动机，不应只为了制造失败收益而复制。

### 2. 不要普遍强迫敌人改变守备

守备替换会直接改变敌方技能原本的防御选择。它适合御坂主动把战斗拖入正面对抗，但大量角色拥有类似能力会破坏守备系统本身的意义。

### 3. 不要让低养成成为隐藏标准答案

允许特殊养成改变玩法，与要求玩家故意不培养角色不是一回事。成功和失败分支必须通过实测保持各自价值。

### 4. 不要为稀有条件堆高基础强度

磁控溅射触发困难，可以拥有明显演出和收益，但不能因为稀有就无限提高伤害、控制与资源收益。尤其全体麻痹会直接改变敌方一整轮行动。

### 5. 不要继续给标记增加功能

标记已经连接异能增伤、技能点削减和磁控溅射条件。继续增加追击、减防或额外层数会使一个短期状态承担过多规则。

## 十五、已确认规则

- 本角色不使用双形态。
- 技能释放后立即获得效果，不需要暖场。
- 不采用长期专属资源循环。
- 拼刀失败或攻击没有造成伤害时施加标记。
- 标记持续1回合。
- 攻击标记目标时，异能伤害提高10%。
- 攻击标记目标时，每个技能最多扣除敌方1点技能点。
- 我方角色丢弃技能时，御坂追加一次随机落雷。
- 只有敌方当前存活人数为3人且全体带有标记时，落雷才升级为磁控溅射并附加全体麻痹。
- 磁控溅射触发后清除敌方全体标记。
- 御坂受到的拼刀伤害降低52%，造成的拼刀伤害提高52%。
- 御坂拼刀成功后的击飞距离变为2倍。
- 御坂处于反击守备时，敌方对她使用单体攻击会把敌方守备替换为反击。
- 一技能在攻击结束时破除敌方前排护盾。
- 二技能每次造成伤害使目标速度降低30，累计最多降低200。
- 超电磁炮在攻击开始时破除敌方群体护盾。

## 十六、待确认边界

- 一、二技能和终结技最终采用的守备类型与守备比例。
- 终结技最终消耗的升华点。
- “标记持续1回合”具体在哪一方的行动节点减少。
- “攻击没有造成伤害”是否同时包括护盾完全吸收、闪避、免疫和其他无效结果。
- 二技能速度降低按每段伤害还是每次技能对每个目标触发。
- 我方丢弃触发是否包括御坂本人、护援技与连携相关行动。
- 一次行动中多名我方角色丢弃技能时，落雷的触发次数。
- 普通落雷与磁控溅射的目标、倍率和攻击属性。
- 磁控溅射判定三名敌人时，召唤物或临时单位是否计入当前存活人数。

## 十七、总结

御坂美琴当前设计的核心不是电击、麻痹或破盾本身，而是她面对正面对抗时的态度：

> 她主动迫使敌人和自己拼刀。赢了就用更强伤害与击飞压倒对手；输了或攻击被完全否定，就给对方留下短期标记，并在下一次攻击中夺回主动。

一技能、二技能和超电磁炮均可立即发挥完整作用，拼刀和标记只会根据实际战况改变御坂的回应方式。队友丢弃带来的随机落雷进一步表现“其他人转入防守时，由御坂补上进攻”，三名敌人同时被标记则形成磁控溅射的稀有高潮。

这套设计使用拼刀、反击守备、护盾、速度、技能点和丢弃等现有系统建立角色个性，没有依赖双形态或长期资源。后续最重要的工作不是继续添加机制，而是实测拼刀成功与失败两条路线、磁控溅射的实际触发率，以及丢弃落雷带来的全队行动经济。
