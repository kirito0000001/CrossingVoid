## 2. B站抓取：哪些能抓、哪些不能

### ✅ 可无鉴权直抓

| 目标 | 方法 | 说明 |
| --- | --- | --- |
| 视频简介/标题/统计 | `api.bilibili.com/x/web-interface/view?bvid=<BV号>` | **完全公开**，返回 title/desc/aid/stat。本次 10 条视频简介全部由此获得 |
| 账号空间页 | WebFetch `space.bilibili.com/<uid>` | 能返回合集列表与视频清单（HTML 内含 JSON） |

### ❌ 需要登录 cookie

| 目标 | 报错 | 说明 |
| --- | --- | --- |
| 评论区 | `-352` / `-403` / `-404` | `x/v2/reply`、`x/v2/reply/main`、`x/v2/reply/wbi/main` 均需登录 |
| 动态详情流 | 部分 JS 渲染 | 动态列表页为 JS 渲染，WebFetch 只能拿到部分 |

> ⚠️ **用户已决定放弃评论区** → 不再尝试绕鉴权。

## 3. agent-browser CLI 使用要点（若后续仍需浏览器）

```bash
# 必须用 nohup + 文件重定向，否则管道缓冲会卡死
nohup agent-browser open "<url>" > /tmp/out.log 2>&1 &
# open 和 eval 要在同一条命令里串联，否则守护进程在两命令之间会回到 about:blank
agent-browser open "<url>" && agent-browser eval "<js>"
```

**已知限制：**
- ❌ agent-browser 使用**自己的** Chromium 配置文件（`~/.agent-browser/browsers`），**不复用用户真实 Chrome 的登录态**。
- ❌ 现代 Chrome 拒绝在**默认数据目录**上开 `--remote-debugging-port`：
  > `DevTools remote debugging requires a non-default data directory.`
  → 想用真实浏览器登录态，必须让 Chrome **带独立用户数据目录**重启（需用户手动操作，本次未做）。
- 截图产物落在 `C:\CrossingVoid\Docs\wiki-research\_shot_*.png`（已清理）。
