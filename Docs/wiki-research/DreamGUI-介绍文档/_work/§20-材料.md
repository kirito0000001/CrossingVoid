## 🚧 未发布的部分（#254–#257）—— **必须标「未发布」**

依据都在 `CHANGELOG.md` 的 **`## Unreleased`** 段（符合项目既定口径）：

| 项 | CHANGELOG 里的条目 |
| --- | --- |
| #254 | **「Bindings update when what they read changes」** —— 编译器记录 `<-` 读到的每个变量与成员；都宣告变化（FieldNotify）时才订阅，变化之间零成本。诊断：`DreamUI.Binding.Dump` / `DreamUI.Binding.ForcePoll 1` |
| #255 | **「Rows update alone」** —— `for` / `each` 的副本各自更新，列表不刷；`Event -> Item.Func()` 路由到自己的项；类型化源时编译器检查 `Item.Member`（**DUI6021**）与 `Item.Func`（**DUI6022**） |
| #256 | **「A C++ `UDreamUserWidget` subclass can declare FieldNotify members」** —— `DreamUserWidget.h` 纳入 `FieldNotificationDeclaration.h`；`DREAM_VM_SET` 是它的 setter |
| #257 | 含在 #254 那条里：**任何实现 `INotifyFieldValueChanged` 的都被订阅**，UE 的 `UMVVMViewModelBase` 也在内，**不依赖 ModelViewViewModel 插件** |

⚠️ **写手必须去 `CHANGELOG.md` 逐条核**：`## Unreleased`（**第 12 行**）起的都是未发布；`## 1.0.0`（**第 224 行**）起才是已发布。
