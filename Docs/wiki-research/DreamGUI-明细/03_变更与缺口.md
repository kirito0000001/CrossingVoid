### 类型覆盖率的复算（本专题的核心主张）

```bash
# 逐类型检查：把仓库里所有反射类型抽出来，逐个在 01_素材账本.md 里做子串命中
python -c "
import re, pathlib
led = pathlib.Path('01_素材账本.md').read_text(encoding='utf-8')
types = {}
for p in pathlib.Path('.').glob('Source/**/*.h'):
    if 'Intermediate' in p.parts: continue
    for m in re.finditer(r'class\s+[A-Z_]+_API\s+([UF][A-Za-z0-9_]+)', p.read_text(encoding='utf-8', errors='ignore')):
        types.setdefault(m.group(1), p.parts[1])
un = sorted(t for t in types if t not in led)
print(f'{len(types)-len(un)}/{len(types)} = {(len(types)-len(un))/len(types)*100:.1f}%', un)
"
```

实测结果：**370 / 370 = 100.0%**（未覆盖 0 个）。

| 轮次 | 覆盖率 | 说明 |
| --- | ---: | --- |
| 首版账本 | 269 / 370 = **72.7%** | 排查发现 **101 个类型**是因为我写了 `_Suffix` 简写（如 `UDreamLayoutContainer` + `_Border`、`UDreamTweener` + `_Float`），**全名没落到纸上**，按类型 grep 找不到 |
| 展开后 | **370 / 370 = 100.0%** | 做了 15 处精确展开（把简写全部换成完整类名），另修 4 处前缀写错：`UDreamPopupLayer` → `UDreamUIPopupLayer`、`UDreamUIFaceBrush` → `FDreamUIFaceBrush`、`UDreamMeshModifierMirror` 实际在 `DreamGUI` 模块（不在 Extensions）、`FDreamUIPostProcessGaussianBlurPS` 原先漏列 |

⚠️ **教训**：写「N 个类型是 A、B、C」时，**简写会让清单失去可 grep 性**。要主张「覆盖了 N 个类型」，就必须让每个类型的**全名**出现在产物里。
