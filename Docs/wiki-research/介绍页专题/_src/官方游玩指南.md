**出货概率：**
```
0~34 抽：1%
35~50 抽：0.5% + 1% ×（抽数 − 34）
51~70 抽：1% + 2% ×（抽数 − 50）
```

## 五、编队界面

- 编队界面有 **6 个角色位**，划分为 **3 组**，**从左到右分别叫做（后排，中排，前排）**。
- 每一组分为**主站（主战）**和**助战**；进入战斗后操控主战，**SUB 位置就是助战**。
- **助战加入战斗后，4 号位技能会变为助战角色的技能。**
- **如果主站和助战具有连携，5 号位技能就会变为双人的合击绝技。**
- 头顶可以看【属性详情】；**角色的数值由主站和助战合并使用**。

### 5.1 属性说明（原文）

| 属性 | 原文说明 |
| --- | --- |
| **速度** | 决定角色在战斗时的行动顺序。**一回合内经过了和人数相同的行动次数，就会进入下一回合**；速度改变会替代掉其他人的行动回合 |
| **生命值** | 血量。大部分情况 ≤0 死亡；**血量上限也决定守备值的数值** |
| **攻击力** | 技能伤害 = **基础攻击力 × 技能倍率** |
| **物防 / 异防** | 游戏伤害分**物理伤害**与**异能伤害**；角色拥有**基础抗性**，**物理抗性角色受到的物理伤害减半**；此数值代表受到对应类型伤害时减免的百分比 |
| **暴击率** | 造成伤害时暴击的概率 |
| **暴击伤害** | 暴击时额外造成的伤害倍率 |

> 另有小节标题「**技能 · 幻形**」（原文仅标题，无正文）。

- **每一次行动开始，给当前行动的阵容 +2 技能点**
- **释放技能消耗对应技能点，释放过后获得等量的升华点**
- 技能有前中后排目标，**根据场上站位判断**

### 6.1 守备机制（★ 本作与原版最大的机制差异）

> 作者原话：「接下来介绍一下和原版零境不一样的机制：**守备（对就是边狱巴士的那个）**」

- **右键或长按技能**，可添加**丢弃标记**；标记**颜色对应守备类型**：

| 守备 | 颜色 | 作用 |
| --- | --- | --- |
| **防御** | 橙色 | 抵消对面的伤害 |
| **反击** | 紫色 | 抵消伤害后再向对面追加攻击 |
| **闪避** | 白色 | 无法被命中 |

**生成规则（释放技能时无论有没有丢弃都会生成）：**

| 守备 | 进度条颜色 | 正常释放 | 丢弃技能 |
| --- | --- | --- | --- |
| **防御** | 绿色 | 血上限 **18%** | 血上限 **36%** |
| **反击** | 深蓝色 | 血上限 **5%** | 血上限 **10%** |
| **闪避** | 白色 | 技能标注的闪避次数 | **次数翻倍** |

- 防御的百分比 = **该守备值里物理盾量的占比**。
- **如果有一种类型的盾被打没了，则会直接退出守备状态**。
- **拼刀**：攻击方与被攻击者**都处于反击守备**时触发；**被攻击者抗性**决定本次拼刀使用的属性类型；**双方谁的守备值更高就胜出**；**血量剩余越少，伤害倍率和击飞力度越高**。
- 结论：**利用好守备技能和控速度，可以通关大部分关卡**。
