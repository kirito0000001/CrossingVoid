## 1.3 被动

- **【最初的声音】**：初音拥有**改变 BGM** 的能力，会随着会场持续升温而增加乐器演奏，提供更多加成和士气。本场战斗**升华点上限 +19 点**。
- **【华彩乐段】**：所有技能变为 **0 消耗**，释放技能选歌，SUB 技能会选择《Blessing》。
- **【世界第一的公主殿下】**：初音处于演唱状态时，使用**守备**可以切歌《World is mine.Inst》，**所有阶段回归初始状态**。

## 1.5 演出 / 美术 / 音频设计

- **舞台材质**：黑色金属、白色金属、白色透明？、五颜六色的发光贴（三个代表色）、玻璃、专门的材质（已有）、金色金属、黑色塑料、网格（话筒音响）
- **关键词**：应援棒、暖场、最能 high 起来的时候放大招、改变 BGM、漂浮的音符、律动特效环、领域展开、聚光灯、律动（多动）、UI 特殊律动闪烁、专属 UI 风格主题
- **BGM 设计**：BGM 附带领域展开，其他音效叠一层压低，回响？；**中途不能随便切歌，一首歌用到底**
- **曲目分配**：一技能 小轻快（icicles）/ 二技能 快节奏燃曲（催眠者）/ SUB 舒缓（妄想感伤）/ 大招 Rise up / 连携：专属曲子、场地（和 YUNA 就是刀剑序列之争的歌曲）
- **寄了/守备暂停**：恢复原本歌曲（初始化时记录歌曲）→ 所以**共三首曲子**，根据第一次点击切歌
- **叠加层乐器顺序**：1 鼓点 → 2 bass → 3 吉他 → 4 钢琴 → 5 其他 → 6 人声（人声放最前；每首曲子顺序可不同，但人声和鼓点要前）
- **预设效果**：1 持续回血 → 2 异能防御提升 → 3 大招双方全部锁血爽打

# 五、由本文档新增的机制结论（供角色页复用）

从初音设计可以反推出**重置版角色页的字段规范**：

1. **定位**：多维标签（如「异能抗性 / 生命治疗 / 群体辅助 / 免死领域 / 闪避守备」）
2. **速度**：单一数值（831）
3. **属性/角色类型**：分为**血量型**、输出型等
4. **位置倾向**：主战 / SUB（援护）性能
5. **特殊效果（状态）**：字段为 `名称 · 最大值 · 持续时间 · 阶段 · 效果`，且**同名效果可叠层**
6. **被动**：独立词条，可改变底层规则（改 BGM、改消耗、重置阶段）
7. **技能四段式**：
   - 类型（群体恢复 / 单体恢复 / 群体增幅 / 闪避 / 防御）
   - 消耗（技能点 或 **升华点/升华费**）
   - 伤害倍率表（**1~5 级** 五档）
   - 「技能成功释放时」触发效果
8. **伤害分两类**：**物理伤害** / **异能伤害**（初音为纯物理，异能标注「无此类型伤害」）
9. **术语确认**：技能点、升华点/升华费、守备、闪避、防御、连携、SUB、锁血、清除负面效果、异能防御
10. 存在**阶段/幕**概念：起始阶段 → 暖场阶段 → 终幕
