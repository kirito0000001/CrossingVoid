## 上游血缘（LGUI 是 **UE 插件**，不是 Unity 项目 —— 修正一轮错判）

> 起因：用户指出「LGUI 几年前就有人从 Unity 搬到 UE 做成插件了，鸣潮用的也是那个」。
> 核证后确认：**上一轮把 LGUI 说成「Unity 侧项目」是错的**，并由此把 A-04⇄A-05 的未决解开了。

### 一手证据（仓库内）

`Docs/Migration.md` 自述本仓库的上游是谁：

> 「one with **assets saved against LGUI or LexUI** — **the upstream this fork started from**」
> 「**Take the old plugin out.** An LGUI or LexUI folder under `Plugins/` has to go before DreamGUI goes in: its classes would be live under the names the redirects map *from*, and a redirect never applies to a name that still resolves.」

`Docs/Migration.md` §3 给出重定向表规模 —— 这是**代码级同源**的直接证据：

| 类别 | 条数 | 覆盖内容 |
| --- | ---: | --- |
| Package | 4 | `/LGUI/` 内容挂载点 → `/DreamGUI/`；`/Script/LGUI`、`/Script/LGUIEditor`、`/Script/LTween` 三个模块 → DreamGUI 名 |
| Class | **395** | **Every LGUI/LexUI class**；prefab 词汇表；控件改名（`UIButtonComponent` → `UIButton` 及其 13 个同胞）；模块拆分搬走的每个类 |
| Struct / Enum | 96 / 124 | 数据侧同上 |
| Function | 74 | 蓝图调用或重写的函数（如 `UDreamUIBehaviour` 的 `Update` → `Tick`） |
| Object | 70 | 模块拆分带走的委托签名 |
| **合计** | **763** | |

`CHANGELOG.md` 记的版本线与之吻合：单模块 1.x → 2.0.0（`2416e3f8`）→ 2.1.0（`3049561a`）→ 1.0.0（描述文件整数 `Version` 从 3 升到 100）。

### 二手证据（外部检索，2026-10-08）

LGUI（Lex GUI）确实是 **Lex Liu 的 Unreal 插件**，在 UE Marketplace / Fab 上架，检索到 v3.4.x，支持 **UE 5.0–5.4**，模块划分：

```
LGUI (Runtime) · LGUIEditor (Editor) · LGUIK2Nodes (UncookedOnly) · LTween (Runtime)
```

**与 DreamGUI 的四个模块一一对应**：`DreamGUI` / `DreamGUIEditor` / `DreamGUIK2Nodes` / `DreamTween`。

其公开功能列表也与 DreamGUI 逐项对得上：3D UI（世界/屏幕空间）、嵌套 prefab、Tween 动画、动态字体、动态 SDF 字体、**动态图集打包**、Rich Text、UIEffect（Shadow / LongShadow / Outline / GradientColor）、**Text Animation**、SpecialEffects（BackgroundBlur / BackgroundPixelate）、`UIWidget` 渲染 UMG、`UIRenderTarget`、`UIFrameCapture`、`UIRecyclableScrollView` 无限循环、MSAA、Substrate 材质模式。

→ **结论：「fork」是代码 fork，上游的 LGUI 就是它的 UE 版**（LGUI 另有 Unity 版本，但被本仓库 fork 的是 UE 版）。A-04⇄A-05 的未决据此**已解除**。
