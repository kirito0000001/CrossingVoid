## 二、战斗公共规则（`wiki补充.md` 要点）

### 2.1 技能点与升华点

| 资源 | 颜色 | 初始 | 上限 | 用途 |
| --- | --- | ---: | ---: | --- |
| 技能点 | 蓝 | 0 | 20 | 释放普通技能 |
| 升华点 | 金 | 0 | 20 | 释放终结技 |

> 敌我各持独立一套。每次行动开始获得 2 技能点；释放技能消耗技能点并获得**等量升华点**。

### 2.2 守备与技能丢弃（★ wiki 战斗区核心）

| 守备 | 颜色 | 正常释放 | 丢弃技能 |
| --- | --- | --- | --- |
| **防御** | 绿 | 血上限 **18%** | 血上限 **36%** |
| **反击** | 深蓝 | 血上限 **5%** | 血上限 **10%** |
| **闪避** | 白 | 标注次数 | **次数翻倍**（闪避3 → 6） |

- 「防御（70%）」= 总守备值中**物理守备占比**，其余为异能守备。**不是减伤 70%**。
- 物理或异能守备**任意一种被打空即退出守备**。
- 丢弃后：原技能攻击与特殊效果**不再结算**，只执行守备，且守备值更高。
- 未消耗的守备值**不会自动清零**，下次释放技能时**刷新**（替换而非累加）。

### 2.3 站位与目标

- 技能标注前排 / 中排 / 后排 / 群体；实际目标按**当前站位 Tag** 判断。
- 前中后排 Tag 会**随死亡与阵容空缺重新分配**（原前排死亡后，最靠前的中/后排会获得前排 Tag）。
- → 「后排死亡后改打中排」是**底层通用规则**，不是某角色的专属追踪。

### 2.4 拼刀（当前已知）

1. 由被攻击者**抗性**决定比较物理还是异能守备值
2. 比较双方守备值，**高者胜**
3. **血量越低，反击伤害倍率与击飞越高**
4. 拼刀结束后**双方守备全部清空**（含闪避次数）

## 三、数值规范（`2D数值规范.txt` + `零境交错数值设计参考.md`）

### 3.1 品质与养成

| 品质 | 生命 | 攻击 | 暴击率 | 暴击伤害 | 物防 | 异能防 | 技能升级次数 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| D | 2000 | 50 | 10 | 10 | 50 | 50 | 6 |
| C | 2500 | 60 | 30 | 30 | 60 | 60 | 8 |
| B | 3000 | 75 | 60 | 60 | 80 | 80 | 10 |
| A | 4000 | 85 | 80 | 80 | 100 | 100 | 12 |
| S | 4600 | 100 | 100 | 100 | 200 | 200 | 16 |

> 角色首次获得默认 **D 级**，重复获得可依次升 D→C→B→A→S。养成类似《赛马娘》的**重复养成**。
> 技能初始 1 级、上限 5 级；S 品质 16 次恰可把四技能全部升满。

### 3.2 属性上限

| 属性 | 单人上限 | 双人（Main+Sub）上限 | 折算 |
| --- | ---: | ---: | --- |
| 攻击力 | 1800 | — | — |
| 生命值 | 18000 | — | — |
| 暴击率原始值 | 9100 | 18200 | 58% |
| 暴击伤害原始值 | 9100 | 18200 | 58% |
| 物理/异能防御原始值 | 9100 | 18200 | 80% |

### 3.3 换算公式（分段线性）

```
防御    D(x) = x×0.0004            (x ≤ 200)
        D(x) = x×0.00004 + 0.072   (200 < x ≤ 18200)
暴击    C(x) = x×0.0002            (x ≤ 200)
        C(x) = x×0.00003 + 0.034   (200 < x ≤ 18200)
```

关键节点：原始 200 → 防御 8% / 暴击 4%；9100 → 43.6% / 30.7%；18200 → 80% / 58%。

### 3.4 连携技等级

```
总技能等级 = Main四技能等级和 + Sub四技能等级和
> 8：连携技等级 = floor(总/8)     ≤ 8：连携技等级 = 1
```
对应：8~15→1级、16~23→2级、24~31→3级、32~39→4级、40→5级。

### 3.5 单次伤害结算顺序（6 步）

```
攻击白值 × 技能倍率 → 攻击方BUFF → 暴击与暴击伤害 → 受击方BUFF
→ 物理/异能防御分别削减 → 守备盾抵扣 → 剩余进入生命值
```
> 物理与异能**同时读取**，分别受对应防御削减后合并。守备盾**逐段实时更新**，打空即碎。

### 3.6 反击与拼刀公式

```
反击倍率 = 1 − 当前生命/生命上限 + 基础反击倍率
        = 已损失生命比例 + 基础反击倍率
反击基础伤害 = 胜者组合攻击力 × 反击倍率
反击击飞力度 = 反击倍率 × 1500
```

### 3.7 五级完整倍率区间（节选）

| 技能情况 | 1级 | 2级 | 3级 | 4级 | 5级 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 无伤害功能 | 0 | 0 | 0 | 0 | 0 |
| 高功能 / 普通护援 | 0.2~0.5 | 0.5~1.2 | 1~1.8 | 1.8~2.6 | 2.4~3 |
| 低费启动 / 1~2人 | 0.3~0.6 | 0.8~1.4 | 1.3~2.3 | 2.2~2.8 | 3~3.8 |
| 普通群体输出 | 0.6~1 | 1.6~2.2 | 2.6~3.2 | 3.2~4.2 | 4.2~5 |
| 普通单体输出 / 单体连携 | 0.8~2 | 1.6~3 | 2.8~4.5 | 4.2~7 | 6.4~9 |
| 高费用高出伤爆发 / 单体升华技 | 1.5~2.6 | 3.5~6 | 7.4~9.8 | 10~13 | 11.4~16 |
| 群体升华技 / 组合升华技 | 1~3 | 2~5 | 4~8 | 7~10 | 9~14 |

> 倍率为**完整技能总倍率**（已计入攻击人数 T 与每目标段数 N）。UI 显示的是取整后的**单段**百分比。
> 完整倍率 = 物理完整倍率 + 异能完整倍率；分段倍率 = 完整倍率 ÷ (T×N)。

### 3.8 D1 / D2 / D3

- **D1 / D2 / D3**：敌方 1 / 2 / 3 个有效目标时，整项技能的完整总倍率
- **单目标最高倍率**：一名敌人可能承受的最高总倍率（用于评价集火/处决/Boss 战）

### 4.1 桐人【SAO】（速度未在文中标出）

- **循环**：单刀准备 → 星光流连击开启二刀流 → 三次强化技能组 → 回到单刀
- **被动·二刀流**：释放终结技后强化接下来 3 次技能组（一/二/终结技计数；援护、连携、守备**不计数**）
- **技能**：回旋盾(0费/防御70%)、水平四方斩(2费/反击50%)、愤怒刺击(3费/反击70%)、星光流连击(8升华/闪避3)
  → 二刀流：双重弧形斩(0费/闪避3)、水平扇形斩(3费/防御60%)、垂直四方斩·改(4费/闪避2)、日蚀(10升华/闪避6)
- **专属状态**：回旋盾(1层/2回合/物理减伤10%)、创伤(16层/2回合/每层受伤+2%)、武器破坏(1层/3回合/伤害-5%)、心意(1层/1回合/伤害+10%)
- **特殊**：水平扇形斩固定六刀，按敌人数平均分配（3人各2刀 / 2人各3刀 / 1人吃满6刀），分配在技能开始时锁定

### 4.2 爱丽丝【UW】

- **循环**：骑士之击积金桂绽放 → 3层解锁金桂飞舞 → 防御架势 或 冲5层 → 终结技转化为金桂绽放术式 → 清空重来
- **被动·记忆解放**：金桂绽放 ≥3 层时，一技能由「骑士之击」替换为「金桂飞舞」（0费→3费、前中排→群体、物理→异能、反击→防御守备、获层 1→2）
- **技能**：骑士之击(0费/反击80%)、金桂飞舞(3费/防御50%)、金桂加护(0费/防御80%/清空全部层数换防御架势最高3级)、斜斩(护援 0费/防御50%)、旋转吧花瓣们(13升华/防御50%)
- ⚠️ 关键：金桂加护**无论多少层都全部清空**，只是防御架势最高 3 级

### 4.3 亚丝娜【SAO】

- **循环**：中子冲击建立攻略之鬼 → 三名队友结束回合时连续追击后排
- **被动·超速支援**：每当一名我方角色**结束回合**，追击当前后排 Tag 敌人，造成**目标最大生命 2%** 伤害；若目标生命已低于 2% 则**直接处决**（一轮最多 3 次触发）
- **攻略之鬼**（二技能获得）存在时，追击伤害 2% → **5%**
- **技能**：四重痛楚(0费/闪避2)、中子冲击(2费/闪避3)、幻闪流星(护援 4费/闪避3/后排封技)、圣母圣咏(10升华/闪避5/自身10层闪光=+400速度)

### 4.4 优纪【ALO】

- **被动·单挑五五开**：敌方仅剩 1 人时，行动开始获得 1 层「专注决斗」（+3% 最终伤害），人数恢复即移除
- **技能**：极速连斩(0费/闪避2/成功释放+1技能点)、绝剑光舞(3费/闪避3)、贯穿之剑(护援 2费/闪避3)、圣母圣咏(10升华/闪避5)
- **速度差机制**：绝剑光舞——若目标速度高于自身，获得等同**速度差**的「拿出对等实力」（1:1 转层，上限 200 层 = 最高 +40% 物理伤害）
- **圣母圣咏结算**：读全场最高速度 → 自身速度提至该值+100（永久累计最多+600）→ 比较提速后速度差 → 转「虚拟世界本地人」（每层 +0.5% 物理，立即生效）
- **状态**：拿出对等实力(200/2回合/+0.2%物理每层)、虚拟世界本地人(无上限/1回合/+0.5%物理每层)、专注决斗(1/动态/+3%最终伤害)

### 4.5 优纪【天使】

- **循环**：常态技能攒残心 → 终结技转残心宣叙并启动 → 残心流中一/二技能按不同速度消耗宣叙 → 归零退出
- **残心**：上限 11 层，无限持续，常态一/二技能各获得 5 层
- **残心宣叙**：上限 11 层，**每层 +3% 暴击率 / +11% 暴击伤害**；转换发生在本次终结技伤害结算**前**
- **消耗速度**：一技能耗 1 层；强化二技能释放结束时耗 4 层或全部剩余（不足 4 层则全耗）
  → 10 层轨迹 `10→6→2→0`，11 层 `11→7→3→0`
- **其它**：绝剑(1层/1回合/终结技异能伤害+11%)、日向流(4层/1回合/每层最终伤害+7%，每额外消耗 1 升华点得 1 层)
- **天使队**：全体 Main 属天使时提供光环；位于 Sub 时可用护援技把当前 Main 临时转为天使

### 4.6 辛克莱【准执柄者】

- **循环**：把 SAN 维持在接近失控，权衡伤害/费用与 45 的失控代价
- **SAN**：最大 45，初始 40，无限持续；**结束自身行动后 −10**；越高伤害越高、终结技费用越低；**达到 45 立即进入侵蚀并锁定自己人**
- **最终伤害修正**：0~9 → −30%；10~19 → −10%；20~29 → 0；30~34 → +10%；35~39 → +20%；**40~45 → +50%**
- **狂信**（施加在**敌方**身上）：上限 30 层；带狂信者被辛克莱**以外**的角色攻击时，每段命中消耗 1 层，每消耗 1 层辛克莱获得 **2 SAN**
- **人格覆盖**（被动，按 SAN 动态改变终结技费用与施加狂信层数）：0~9→10升华/10层；10~19→8/6；20~29→6/4；30~34→4/2；35~39→2/1；**40~45→0/0**
- ⚠️ 命名问题：原版「狂信」是辛克莱自身状态，现用于敌方 → 建议改名（异端 / 净化目标）

### 4.7 初音未来【NT】★ 最完整

- **循环**：6 点终结技主动开场 → 华彩乐段免费选歌 → 每次行动推进暖场 → 到达「魔法未来」备 39 升华点 → 开启三回合终幕 → 结束后回初始
- **速度 831**（对应 8 月 31 日发行日）
- **华彩乐段**：首次/上轮 Live 结束后释放终结技进入；下一次行动所有技能 0 消耗，一技能《icicles》/ 二技能《妄想感伤代偿联盟》/ 终结技《Rise up》/ Sub《Blessing》
- **暖场**：每次正常释放技能推进一阶段，**守备会中断并重置整场演出**
- **魔法未来**：暖场第五阶段后，终结技消耗变 **39 升华点**、其他技能全禁用（升华点不足 39 只能跳过行动——**已知卡手风险**）
- **终幕**：释放后持续三次初音行动，我方清除全部负面，全体获「通往未来的音乐」
- **技能**：拼凑的断音(0费/群体恢复/闪避2)、亢奋剂舞(2费/单体恢复/防御20%)、深海少女(护援 4升华/群体恢复/防御30%)、让其响彻(6升华/群体增幅/闪避3)
- **效果**：大葱打Call(9层/3回合/每层减 9% 物理伤害)、CV01(+16%治疗)、Miku(回复2技能点1升华点)、公主殿下的骑士团(回复已损失3.9%血)、39感谢祭(双方暴击率+16%)、魔法未来(我方异能防+3%/敌方−9%)、通往未来的音乐(不死+每人行动结束回5技能点+异能伤害+16%+速度+831)

### 4.8 御坂美琴（机制设计中，数值未定）

- **核心**：主动进反击守备 → 迫使单体攻击者进入拼刀 → 胜负各有收益
- **拼刀专精**：拼刀受伤 **−52%**、拼刀伤害 **+52%**、拼刀成功后击飞距离 **×2**
- **强制反击守备**：御坂处于反击守备时，敌方**单体**攻击她会被替换为反击守备 → 强制进入拼刀（群体攻击不受影响）
- **标记**：拼刀失败 **或** 攻击未造成伤害时施加（1 回合）；攻击带标记目标时扣敌方 **1 技能点** + 御坂对该目标**异能伤害 +10%**（每技能最多触发一次）
- **丢弃落雷**：我方丢弃技能时，御坂对随机敌人追加落雷
- **磁控溅射**：触发落雷时若敌方 3 人**全部带标记** → 升级为超大范围落雷，伤害更高 + 敌方全体麻痹 1 回合
